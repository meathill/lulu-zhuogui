## 2.1 鬼与祟团（生态）

- **人死之后变成鬼。** 阴差会回来收。但**横死**，或**怨念未了**的鬼，可能会回避阴差，或者一时收不走，滞留阳间。
- **完整的鬼**还保留模样、记忆与执念，能沟通——多数温情线属于此类。时间一长：
  - 会被日光等阳物一点点破坏；
  - 会被有**吸阴**之性的物件肢解（老槐树、无人祭拜的牌位、枯井、某些阵眼）；
  - 也会被别有用心的坏人用咒术拆解。
- 无论哪条路，鬼都会**破烂**，人形与神识剥离，剩下可聚可散的负能量碎块——本作称之为 **祟团**。
- **比喻**：完整的鬼 ↔ 祟团 ≈ 肉体 / 动物 ↔ 蛋白质。祟团可聚拢、分裂，也可被其它鬼或邪灵吸收。
- 鬼的常见状态：
  - **有形之鬼**：人形尚在，能对话。
  - **孤魂**：记忆只剩一两个执念循环（一直等车、一直送同一单）。
  - **祟团**：无意识黑团，本能扑向活人阳气；塔防的主要杂兵。可聚合为更大的「淤」类 Boss。
  - **附身者**：祟团或鬼钻进活人，宿主高烧、梦游、胡话、性情大变。
  - **厉鬼 / 煞**：执念转为纯粹恶意，会算计活人。Boss 多为此类。
  - **失去形体的碎渣 / 孤魂野鬼（弱）**：连祟团都算不上完整的残渣，靠吸食环境中残留的**阳气碎屑**苟活（见步道设定）。
- **驱散的代价（贯穿全文）**：打碎完整的鬼 → 祟团扩散 → 被吸阴物、地下渠、锁怨井或邪灵吸收。平台鼓励驱散，等于在给井喂食。——**劝善对照**：贪「干净、单价高」，井里的东西高兴。

## 2.2 驱祟师与符箓（屏幕画符）

- 驱祟师借符箓之力镇、打、净、度。口诀收尾：「**急急如律令**」。
- **符箓之力可以经由「目」传递**——只要驱祟师能「看见」，镜头就是眼睛。远程驱祟因此成立。镜头越差、延迟越高，符力越弱（**摄像头升级**的经济理由，见 `04`）。
- **画符 = 在屏幕上连点成符**：符阵按顺序亮起光点，记住顺序，一笔连完。快、准、不碰红色禁点，符力越强。不需要黄纸与朱砂笔；平台把符阵投射到师傅端画面上。
- 符分四类，前期逐步解锁：**镇守 / 攻击 / 功能 / 仪式**（一关教一类或一种，对标 PvZ）。
- **秩序隐喻（v3.1）**：驱祟师夜里接单，像现实里还有人值班的警察——有鬼也有人捉鬼。你不是猎奇，是保一方平安；符箓是「工具」，心是「守夜的人」。

## 2.3 鬼的四种处理方式（含劝善功能）

| 方式 | 说明 | 收益 | 代价 / 后果 | **劝善读法** |
|---|---|---|---|---|
| **击退（击破外层）** | 把鬼打跑或打散表层 | 低收入，快 | 鬼可能回来；订单可能「复购」（平台喜欢复购） | 敷衍了事——像只赶人、不解决问题 |
| **驱散** | 彻底打碎完整的鬼 | 收入最高，平台评分加成 | 功德下降，杀孽增加；化为祟团流入地下怨脉，喂大锁怨井与最终 Boss | **反劝善对照**：贪快贪钱；聊斋里坏蛋娶不到狐仙——这里贪驱散的师傅结局更糟 |
| **制服后报阴** | 定住后一键呼叫阴差带走 | 中等收入，加功德 | 地府按流程处理；温情线通常结束（有时圆满，有时遗憾） | **秩序一侧**：交给管事的人，走正道 |
| **收服** | 与鬼立契，使其成为协助者 | 无直接收入，稀有 | 仅剧情绑定可收；需契约符；后期关卡可登场帮忙 | 听完故事、立下约定——向善才换同盟 |

> 教学节奏：击退 vs 驱散在早期拆开感知；四种完整 UI 在教学弧中后段一次讲清（见关卡表）。  
> **设计口径**：四种都「能通关」；向善选项在旗标、Boss 强度、结局上记账，不在当关锁死进度。

## 2.4 「路路捉鬼」平台

- 表面：夜间上门服务的零工平台；隐藏业务——**远程驱祟**。师傅在家接单，平台派单、结算、评分。
- 平台逻辑：**驱散单价最高**（「客户要的是干净，不是故事」）。准时率、好评率、复购率全部量化。AI 客服「**小路**」语气永远甜，内容永远扎心。
- 暗线：平台与地府「临江分局」有外包协议。平台为了单量鼓励驱散，地府头疼——祟团没人收，全往地下冲。
- **反劝善对照（v3.1）**：小路推「金牌驱散手」、加价驱散——像只认罚单金额的坏制度。驱鬼者若跟着平台贪，就离「秩序一侧」越远，离井越近。结局 A 可暗示地府建议取消驱散单价加成——制度也能被劝回头。

## 2.5 城市：临江市

- 虚构的中国南方中型城市：一条江，一座老桥，一片正在拆迁的老城区。
- **反复出现的地点与物件**：
  - **槐安里**：老城区，拆迁中。老槐、槐神龛、水泥封住的老井（锁怨井）。
  - **永宁桥**：跨江老桥，桥头事故频发，桥墩下曾有镇水铜牛。
  - **老渠**：地下旧排水渠，祟团最终顺渠流向槐安里。——**劝诫钩**：别逞能下渠、别夜里探灵凑热闹。
  - **夜班 404 路**：末班公交，途经已撤的「槐安里站」，终点永宁桥。
  - **铜铃声**：多关环境音里若有若无的铜铃——槐神龛檐角。
  - **红色小皮鞋**：多关监控角落一闪——囡囡的标志。
  - **生活场景新增强调**：电梯轿厢、小区步道、楼道感应灯走廊、24h 便利店、城西六楼出租屋书桌。
- **城隍失位**：城中七处镇物构成的镇怨阵靠民间香火维持。旧城改造令镇物失效，叠加平台驱散产生的祟团，锁怨井接近临界。——**秩序隐喻**：镇物像治安岗亭；香火断了，夜里就更需要有人值班。

## 2.6 小区步道与阳气（劝善功能写明）

> 布丁弧初见场景的世界观支撑；也适用于其它「人散之后」的户外监控关。  
> **劝善功能**：用恐吓感把人往「晚上早点回家、别在小区瞎转」上劝——像评书鬼故事里「别游野泳」。

- **白天 / 傍晚人多时**：小区步道、健身区、花坛边聚集活人。人来人往踩过、说过、笑过，会在地面与空气里留下一层肉眼看不见的 **阳气余温**——像刚散场的球场还热着。
- **人散之后（通常 22:00 后）**：阳气开始冷却、碎裂，变成失去形体的碎屑。形不成完整鬼的**孤魂野鬼 / 细祟团**会聚在步道、路灯死角、绿化带阴影处，**趴着吸食**这些碎渣，像野猫舔翻倒的外卖。
- **恐吓感旁白 / 老周台词方向**（布丁初见关必用一句；其它户外关可复用半句）：
  > 老周：晚上不要在小区瞎转哦～人一走，剩的那点阳气，就归它们啃了。你看监控里那团团黑影，不是在散步，是在吃饭。
- **生活劝诫延伸**（教学旁白可用，不打断节奏）：
  - 电梯半夜自己停——「人少、阳气断得干净的地方，别逞能夜游。」
  - 渠口探灵——「别为了直播下渠下井；活人失踪按活人办，鬼也救不了逞能的人。」
  - 桥头鬼打墙——「夜路急单，命比准时率贵。」
- **与布丁的关系**：布丁作为有形狗鬼，夜里也会晃到步道附近——它不是来吸阳气的，它是在找「放学的味道」。祟团冲保安 / 晚归的人时，它会本能去挡。玩家第一次看到的，是「步道上肥敦敦的黄白影 + 一圈趴着吸食的黑渣」。
- **设计用途**：解释为何「看起来人很多的生活场景」夜里会突然脏；给环境交互（脚步声热点、阳气碎光特效）提供理由；为后续「打碎完整鬼 → 祟团往低处流」做感官预热；**把「晚上别瞎转」写进世界观，而不是贴在 UI 上的标语。**

## 2.7 地府

- 地府临江分局·夜巡科：收拢滞留阳间的鬼魂，走流程、送轮回。——**秩序一侧的编制内**：像警局夜班科。
- 地府也在数字化：阴差用平板登记，「报阴」走路路捉鬼 App 的一键接口，经常卡顿。
- 往生符需地府授权；前期只能向阴差借用，后期凭功德解锁。
- 马科长口头禅方向：「碎的东西不会没，只会往低处流。」——既是生态课，也是劝善记账。
