# 01 · 世界观设定

> design-v4.2 ｜ 小地方刑警遇大案；城镇化信仰断裂；公办体制运作；祟裂与灵聚；降灵入轮回；布丁奈何桥救主；符贴环境对鬼生效（唯附身贴人/五雷地掷引雷）；少人与路径可读。

## 2.1 鬼与祟团（生态）

- **人死之后变成鬼。** 阴差会回来收。但**横死**，或**怨念未了**的鬼，可能会回避阴差，或者一时收不走，滞留阳间。
- **完整的鬼**还保留模样、记忆与执念，能沟通——多数温情线属于此类。时间一长：
  - 会被日光等阳物一点点破坏；
  - 会被有**吸阴**之性的物件肢解（老槐树、无人祭拜的牌位、枯井、某些阵眼）；
  - 也会被别有用心的坏人用咒术拆解。
- 无论哪条路，鬼都会**破烂**，人形与神识剥离，剩下可聚可散的负能量碎块——本作称之为 **祟团**。
- **比喻**：完整的鬼 ↔ 祟团 ≈ 肉体 / 动物 ↔ 蛋白质。祟团可聚拢、分裂，也可被其它鬼或邪灵吸收。
- 鬼的常见状态：
  - **有形之鬼**：人形尚在，能对话。
  - **孤魂**：记忆只剩一两个执念循环（一直等车、一直送同一单）。
  - **祟团**：无意识黑团，本能扑向活人阳气；塔防的主要杂兵。可聚合为更大的「淤」类 Boss。
  - **附身者**：祟团或鬼钻进活人，宿主高烧、梦游、胡话、性情大变。
  - **厉鬼 / 煞**：怨念太强时，鬼可**吞食吸收其它鬼**，变成**厉鬼**，更难打；执念也可转为纯粹恶意、会算计活人。Boss 多为此类。
  - **盘踞**：有些鬼找到固定的阳气 / 念力来源，会**长期盘踞**吸食——例：布丁弧**林小禾**家的**梦魇 = 厉鬼盘踞卧室吸阳**（第10首次Boss）。玩家从画面应能感到「它赖着不走、越吸越沉」。
  - **失去形体的碎渣 / 孤魂野鬼（弱）**：连祟团都算不上完整的残渣，靠吸食环境中残留的**阳气碎屑**苟活（见步道设定）。
  - **灵**：魂魄碎片经**灵物**汇集而成的一缕（可沟通、可送走）；气质「集天地灵气，汇日月光辉」，可人血作媒、念力加持；**即将成型**时可补碎片灌满再送投胎（第 6 主课）。**本作一两关量级**。详见 §2.1a。
- **打碎与驱散的生态代价**：把完整的鬼暴力打碎，祟团会四散流入下水道暗渠，最终被深埋在老槐树下的锁怨井吸收。更深层的时代根源是**城镇化狂飙后民间信仰循环的彻底断裂**：过去有土地庙、神龛与宗祠引渡告别，如今大拆大建后香火断绝，逝者来不及告别，粗暴轰碎只会让失去灵智的怨念在暗渠发酵成灾。——**劝善对照**：贪快图省事，井底的恶煞就吸得越饱。

## 2.1a 祟裂与灵聚（对照）

鬼破烂之后，常见两条路——**裂成祟**，或（少见地）**聚成灵**：

| | **祟**（裂） | **灵**（聚） |
|---|---|---|
| 从哪来 | 完整的鬼被日光、吸阴物、咒术拆碎 | 魂魄碎片碰上合适的**灵物**，有机会再汇起来 |
| 长什么样 | 无意识黑团，本能扑阳气；可聚成更大的「淤」 | 有一点神识与模样的一缕；能听能送，不是杂兵 |
| 气质 | 负的、往低处流的 | 「集天地灵气，汇日月光辉」——旧话味，但**本作量级小**，撑一两关演出就够 |
| 媒介 / 条件 | 怨、阴、井、渠；驱散等于帮它裂得更碎 | 灵物本身；可**人血**作媒、**念力**加持（香火、真心惦记、空祭里那点不散的念） |
| 玩法对照 | **驱散** → 祟扩散 → 喂井 / 怨脉 | **降服魂灵 → 送到地府投胎入轮回**（挂阴差 / 报阴 / 往生已有通道） |
| 挂关 | 多数清潮关；Boss 淤 / 千怨吃的就是这条 | **第 6** 成型灵（主教学：补灵→送投胎）；**第 4** 末班可选轻量（主课驱离符）；**第 17** 桂英（温情加深：听完再送） |

人话一句：祟像打碎的碗渣——扎脚、往低处冲；灵像把碎瓷片粘回一小盏灯——还能照一下路，然后交给阴差送去投胎。

祟团链（聚散、喂井、马科长那句「碎的东西不会没」）**照旧**；灵是对照支线，不替代祟生态。

## 2.1b 祟为何聚（吸引点 · 短）

孤魂与祟团夜里扎堆，多半是奔着**吃的**或**念力窝**去的——不是抽象刷怪点。常见钩子：

- **废弃神龛 / 店铺外贡品 / 路边烧纸**：残祭、香火、纸灰未冷，偷偷吃或疯抢。  
- **聚阴古树**：小区、公园、学校角落阴气沉，细祟趴根。  
- **误当神迹的形似神佛**：污渍光影像佛像，有人祭拜，念力汇成饵。  
- **空祭**：自发纪念有贡品有念力，但目标不在场（或不在阳间常理位）。

电梯里看广告仍是第 1 关特例。玩法细则与挂关见 `04`「祟为何聚」、`03` / `05_levels`。

## 2.1c 路径可读（设计原则）

玩家看画面应能猜「**鬼从哪来、往哪去**」。画面可以强调（箭头光、雾色、涌出特效），但**逻辑优先**：先想通生活理由，再决定镜头怎么拍。

- **攻击目标**：谁在吸阳 / 谁被护送 / 谁在完成空祭——画面里应一眼能认。例：路口香炉上的面包与烟 → 空祭进度；靠窗旁座的驱离符 → 护人。少画全身路人（`00` 少人原则）。  
- **涌出处**：墙角、树后、下水道、门缝、货架脚——须落在当前机位能看见的地方，且说得通「这儿为什么漏」。  
- **吸引点**：香炉、贡品、古树根——既是钩子，也是路径锚；玩家点开热点应能对上「它们奔这儿来」。

写关检查：遮住 UI 文字，只看画面，能否猜出本关路径？猜不出就改地图或机位，别加抽象说明弹窗。

## 2.2 驱祟师与符箓（屏幕画符与实战规则）

- 驱祟师借符箓之力镇、打、净、度。口诀收尾：「**急急如律令**」。
- **符箓之力可以经由「目」传递**——只要驱祟师能「看见」，镜头就是眼睛。远程驱祟因此成立。镜头越差、延迟越高，符力越弱（**摄像头升级**的经济理由，见 `04`）。
- **画符 = 在屏幕上连点成符**：符阵按顺序亮起光点，记住顺序，一笔连完。快、准、不碰红色禁点，符力越强。系统把符阵投射到师傅端画面上。
- **符箓放置与生效规则（v4.2 定稿）**：
  1. **符只能贴在屋内/环境位置上**（门框、门缝、门下缝、窗台、走廊地面、灶台等固定位点），通过勾连阳气形成结界，对经过的鬼祟生效；
  2. **唯独活人被「附身」时**（如便利店醉汉），显形咒/清心符才允许贴在活人身体上（如后颈、额头），逼出阴煞；
  3. **五雷符等攻击符**：不需要往鬼身上硬糊，**选中地面扔下去引天雷**，落地引天火雷光炸碎阴气。
- 符分多类，前期逐步解锁：**镇守 / 攻击 / 控场（定神） / 功能 / 仪式**。已贴符可**撕符**回收位点。
- **秩序隐喻（公办守夜人）**：驱祟师夜里值守，像夜班民警——有鬼也有人捉鬼。老周名言：「派出所管人间，我们管阴间杂事」。你不是猎奇，是保一方平安；符箓是工具，心是守夜的公心。

## 2.3 鬼 / 灵的处理方式（含劝善功能）

| 方式 | 说明 | 收益 | 代价 / 后果 | **劝善读法** |
|---|---|---|---|---|
| **击退（击破外层）** | 把鬼打跑或打散表层 | 低收入，快 | 鬼可能回来；订单可能「复购」（基层反复出警） | 敷衍了事——像只赶人、不解决问题 |
| **驱散** | 彻底打碎完整的鬼 | 结案补贴高，考核结案率好看 | 功德下降，杀孽增加；化为祟团流入地下怨脉，喂大锁怨井与最终 Boss | **反劝善对照**：贪快图省事；考核导向的官僚懒政——碎渣留给地下，遗祸无穷 |
| **制服后报阴** | **定神**顶住后 UI**召唤阴差**带走（可先驱离绕进交接区）；阴差**只收完整/有名魂**，普通祟团拒收 | 中等津贴，加功德 | 地府按流程收容；温情线通常结束（有时圆满，有时遗憾） | **公办正道**：交给对口部门（地府夜巡科）走正规流程 |
| **降灵入轮回** | 降服魂灵（**即将成型的灵**补满后，或灵物汇成的灵 / 引魂灯收束执念），走阴差 / 往生通道**送去投胎** | 中等津贴，加功德；温情旗标 | 须先成型/收束并定神稳住；念力不够则聚不起或中途散成祟 | **送走投胎**：不打碎、不喂井；最干净的一条 |
| **收服** | 与鬼立契，使其成为协助者 | 无直接津贴，稀有 | 仅剧情绑定可收；需契约符；后期关卡可登场帮忙 | 听完故事、立下契约——向善才换同盟 |

> 教学节奏：击退 vs 驱散早期拆开感知；处理 UI 在教学弧中后段讲清；**降灵入轮回**：**第 6** 主教学（补灵成型→送投胎）、**第 4** 可选轻量、**第 17** 桂英温情加深（第6学会流程，听完再送）。  
> **设计口径**：各选项都「能通关」；向善在旗标、Boss 强度、结局上记账，不在当关锁死进度。  
> **通道**：降灵入轮回挂已有阴差 / 报阴 / 往生机制，不另开一套操作系统。

## 2.4 「路路捉鬼」机构性质与运作

- **机构全称**：临江市民俗事务服务中心（对外公众端与调度系统统称「路路捉鬼」）。
- **体制属性**：**挂靠在市民政与宗教事务局下面的半事业单位，业务直接受辖区属地派出所指导监管**。老周原话：「派出所管人间治安，我们管阴间杂事。」基本上是地道的公办单位做派。
- **运行逻辑**：师傅在家远程值班接单，系统派单、考勤、核销津贴、评定星级。AI 客服「**小路**」是政务数字化改造后上的智能外包语音，用标准公家客服腔调催达标率和结案进度。
- **与地府的体制协作**：地府临江分局夜巡科（马科长）是阳间民俗中心的**阴司对口业务单位**。两边属于跨部门业务协作。由于阳间部分见习人员贪图“结案率”快速拿五雷轰碎恶鬼，导致大量祟团流入下水道，马科长天天跟老周扯皮抱怨“地府下水管全堵了”。
- **基层片警式的琐碎与枯燥（小地方刑警遇大案）**：区别于侦探故事里天才神探与美女助手住进暴风雪山庄智斗怪人的浪漫奇观，这里的守夜日常与当代法制刑侦剧里的基层小民警高度一致——枯燥、繁琐、疲惫。绝大多数时间是盯着屏幕翻看几个小时的昏暗监控、核对报修单与水电气表、走访老保安与老街坊。遇到的鬼魂也多是灰头土脸、一时想不开或被生活拖垮的普通人（急着赶倒计时的外卖小哥、怕老伴饿肚子的痴呆老人、走失的家犬）。老周作为统管多名巡查员的老调度，每天应付这些就像片警挨户敲门走访一样觉得乏味沧桑，常态是“差不多就行了、早点弄完早点交班”。
- **灾祸根源：城镇化狂飙与民间信仰循环打破**：锁怨井与渠底怨煞的大爆发，**绝非某家黑心公司命令员工打碎鬼魂导致的商业阴谋**。深层病根在于过去三十年小地方狂飙突进的城镇化与经济快速发展——原本在传统熟人社会里，生老病死有土地庙、古槐神龛、老桥铜牛、岁时祭祖、流水席超度一套完整的民间信仰循环来消解执念；但大拆大建将这些连根拔起，老街推平、神龛被砸、人心在高速运转中被生活逼得顾不上悲伤与悼念。失去归宿与倾听的三十年人间苦难，无处安放，顺着城市的排污渠深处沉淀发酵，在临江市一次性集中爆发！
- **反劝善对照**：小路推的“高驱散津贴”，反映的是体制内只看“表皮干净结案率”、不顾后续生态后果的官僚懒政。驱鬼者若跟着指标贪驱散，就成了恶政的帮凶，最终在锁怨井前偿还总账。结局 A 暗示市局与地府联合发文取消驱散指标奖励，让制度回归向善。

## 2.5 城市：临江市

- 虚构的中国南方中型城市：一条江，一座老桥，一片正在拆迁的老城区。
- **反复出现的地点与物件**：
  - **槐安里**：老城区，拆迁中。老槐、槐神龛、水泥封住的老井（锁怨井）。
  - **永宁桥**：跨江老桥，桥头事故频发，桥墩下曾有镇水铜牛。
  - **老渠**：地下旧排水渠，祟团最终顺渠流向槐安里。——**劝诫钩**：别逞能下渠、别夜里探灵凑热闹。
  - **夜班 404 路**：末班公交，途经已撤的「槐安里站」，终点永宁桥。
  - **铜铃声**：多关环境音里若有若无的铜铃——槐神龛檐角。
  - **红色小皮鞋**：多关监控角落一闪——囡囡的标志。
  - **生活场景新增强调**：电梯轿厢、小区步道、楼道感应灯走廊、24h 便利店、城西六楼出租屋书桌。
- **城隍失位**：城中七处镇物构成的镇怨阵靠民间香火维持。旧城改造令镇物失效，叠加体制基层为图结案快草率驱散产生的祟团，锁怨井接近临界。——**秩序隐喻**：镇物像治安岗亭；香火断了，夜里就更需要有人值班。

## 2.6 小区步道与阳气（劝善功能写明）

> 布丁弧初见场景的世界观支撑；也适用于其它「人散之后」的户外监控关。  
> **劝善功能**：用恐吓感把人往「晚上早点回家、别在小区瞎转」上劝——像评书鬼故事里「别游野泳」。

- **白天 / 傍晚人多时**：小区步道、健身区、花坛边聚集活人。人来人往踩过、说过、笑过，会在地面与空气里留下一层肉眼看不见的 **阳气余温**——像刚散场的球场还热着。
- **人散之后（通常 22:00 后）**：阳气开始冷却、碎裂，变成失去形体的碎屑。形不成完整鬼的**孤魂野鬼 / 细祟团**会聚在步道、路灯死角、绿化带阴影处，**趴着吸食**这些碎渣，像野猫舔翻倒的外卖。
- **恐吓感旁白 / 老周台词方向**（布丁初见关必用一句；其它户外关可复用半句）：
  > 老周：晚上不要在小区瞎转哦～人一走，剩的那点阳气，就归它们啃了。你看监控里那团团黑影，不是在散步，是在吃饭。
- **生活劝诫延伸**（教学旁白可用，不打断节奏）：
  - 电梯半夜自己停——「人少、阳气断得干净的地方，别逞能夜游。」
  - 渠口探灵——「别为了直播下渠下井；活人失踪按活人办，鬼也救不了逞能的人。」
  - 桥头鬼打墙——「夜路急单，命比准时率贵。」
- **与布丁的关系**：布丁作为有形狗鬼，夜里也会晃到步道附近——它不是来吸阳气的，它是在找「放学的味道」。祟团冲保安 / 晚归的人时，它会本能去挡。玩家第一次看到的，是「步道上肥敦敦的黄白影 + 一圈趴着吸食的黑渣」。
- **设计用途**：解释为何「看起来人很多的生活场景」夜里会突然脏；给环境交互（脚步声热点、阳气碎光特效）提供理由；为后续「打碎完整鬼 → 祟团往低处流」做感官预热；**把「晚上别瞎转」写进世界观，而不是贴在 UI 上的标语。**

## 2.7 地府

- 地府临江分局·夜巡科：收拢滞留阳间的鬼魂，走流程、送轮回。——**秩序一侧的编制内**：像警局夜班科。
- 地府也在数字化：阴差用平板登记，「报阴」走路路捉鬼 App 的一键接口，经常卡顿。
- 往生符需地府授权；前期只能向阴差借用，后期凭功德解锁。
- 马科长口头禅方向：「碎的东西不会没，只会往低处流。」——既是生态课，也是劝善记账。
