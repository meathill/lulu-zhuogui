# 03 · 关卡顺序总表

> design-v4.0 ｜ **序章 + 25 关**；**少人原则**；教学链第4驱离→第5定神按住老闵→第6成型灵送投胎保留。  
> **布丁弧重切**：第7收服/驱散；第8、9穿插非Boss；第10林小禾卧室·梦魇=**全作首次Boss**。  
> **全关卡塔防**：贴符=塔；每关须有路径逻辑 / 守护目标 / 失败条件 / 一大波 / **机位**；中后可挂**吸引点**与**不稳手机位**。  
> **机位总则**：第 **1–4** 关**单机位**；第 **5** 关起**可多机位**；复杂关可临时借 **NPC 手机**。符位点须在当前可用机位画面内（`04` §4.0）。构图遵守**少人原则**。  
> 每关目标时长：短教学 4–5 分钟；常规 5–7 分钟；Boss / 终章 8–12 分钟。  
> 失败通用：老周劝退 → 本关重开 / 读取进度（见 `04` §4.0）。

## 为何 25 关（非 24）

第10定为首次Boss后，原「安神首教+卧室决战」拆成两关（第9浅梦预习 + 第10Boss）；原第10–24整体后移一格。终章五关与中段温情线不合并——合并会削掉可玩段落。故定稿 **序章 + 25 关**。
