## 指导思想（一行）

鬼故事劝人向善（晚上别瞎转、别逞能下渠）；有鬼也有人捉——**路路捉鬼 = 秩序一侧**；平台催驱散 = 反劝善对照；**少人**；**机位克制**；**符只对鬼祟**（无安神）；撕符；定神→召唤阴差。详见 `00_overview.md` §1.3。
