## 指导思想（一行）

鬼故事劝人向善（晚上别瞎转、别逞能下渠）；有鬼也有人捉——**路路捉鬼 = 秩序一侧**；平台催驱散 = 反劝善对照；**少人**：画面优先鬼/道具/环境。详见 `00_overview.md` §1.3。
