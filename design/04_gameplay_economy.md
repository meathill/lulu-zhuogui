## 4.0 塔防总则

### 一句话

**贴符 = 种塔**；祟 / 鬼沿**说得通的路径**走向**守护目标**；浓度或目标破线即失败。点消只作极轻辅助（如路上的飘屑），**不以点消为主玩法**。

### 核心对照

| 塔防概念 | 本游对应 |
|---|---|
| 塔 | **符位**：镇守符贴在缝隙 / 路口 / 门窗等固定位点，持续对路径上的祟生效 |
| 手操攻击 | **五雷等攻击符**：连点成符砸向高威胁目标 / Boss；补塔力不足的瞬间 |
| 敌人路径 | 祟团 / 有名鬼沿地图路线移动；路线须有**生活逻辑**（见下） |
| 守护目标 | 活人阳气/惧值、电梯浓度、交接区定神、成型条、盘踞核、护送单位、灶台、书桌等 |
| 资源 | **符力**（关内主资源，替 PvZ 阳光）、符纸、糯米、铜铃次数（约第10起作打断）、关前商店补给 |
| 一大波 | 关内至少一个「浓度骤升 / 路径变长 / Boss 入场」节点（旗标波） |

### 路径逻辑（写关必须交代）

路线不是抽象格子，要能用一句话解释「为什么鬼往那儿走」；并且**玩家看画面应能猜「从哪来、往哪去」**（逻辑优先，画面可强调，见 `01` §2.1c）：

- **小区夜路**：人散后阳气碎渣浮在步道上，祟团来啃；角落**聚阴古树**更易扎堆（见「祟为何聚」）。护送夜路时，**被护送的人**就是攻击目标；墙角 / 树后 / 下水道是涌出处。  
- **电梯**：鬼渣爱聚电梯里看广告，从门缝、门下缝、电缆井、楼层缝往轿厢聚（入口须落在机位画面内，见下）。**第 1 关特例**，不另挂吸引点。  
- **地漏 / 门缝 / 巷角**：往低处、往宿主阳气、往吸引点（香炉等）汇；涌出处须入画且说得通。  
- **公交车厢**：善鬼占座也正常坐；驱离符把它们往**后半节**赶，到站自然下；护靠窗活人座 = 旁座贴驱离符。  
- **停车场交接**：有名鬼环线巡逻；驱离符逼**绕路**进交接区，定神符**顶住**，撑到阴差到来（第 5）。  
- **成型灵天井**：魂魄碎片沿巷缝汇向即将成型的灵；定神稳住后送投胎（第 6）。  

- **符箓放置与实战总则（v4.2 定稿）**：
  1. **符只能贴在屋内/环境位置上**（门框、门缝、门下缝、走廊地面、窗台、灶台等固定位点），通过勾连空间阳气形成防御或改道结界，对经过的鬼祟生效；
  2. **唯独活人被「附身」时**（如第3关醉汉），显形咒/清心符才允许贴在活人身体上（如后颈、额头），逼出附身体内的阴煞；
  3. **五雷符等攻击符**：不需要往鬼身上硬贴，**选中地面扔下去引天雷**，落地引天火雷光炸碎阴气即可。
- **驱离符**（第4首教、第5巩固）：对标植物大战僵尸的大蒜——**只改路线、不造成伤害**；贴在车座或路口，公交赶善鬼往后半节；停车场逼老闵绕进交接区。画面贴的是符纸光效，不是实物蒜。  
- **定神符**（第5首教、第6巩固）：把目标**顶住/稳住**——**不打碎魂魄**。定神成功后 UI 亮起**召唤阴差**按钮；阴差**只收完整/有名魂**，普通祟团点了无效或马科长拒收。旧称「定身符」一律改本名。  
- **撕符**：所有已贴符可**手动撕掉**（回收位点 / 打断效果），用来把不同魂/祟分开（第7主课；全局可用）。  
- **梦境 / 盘踞**：怕与执念铺成的巷子接到卧室；厉鬼可**长期盘踞**固定阳气窝（例：第 10 关梦魇·首次Boss）。对盘踞鬼用定神（顶住）、镇宅（阻挡）、显形、五雷（扔地上引雷轰击）等打鬼工具。布丁在奈何桥头逆冲回阳，冲入梦境舍身撕咬梦魇核心。  
- **祭拜 / 烧纸 / 空祭 / 误拜神迹**：见下节「祟为何聚」——写关至少点名一类，作路径源或改道钩。


### 祟为何聚（路径吸引点）

祟 / 孤魂不是随机刷兵：它们奔着**吃的、念力、阴气窝**来。写关用一句话点明本关吸引，玩家侦察热点可点开半句风味。

| 吸引类型 | 一句话 | 设计用途 |
|---|---|---|
| **废弃神龛** | 香火断了，鬼仍偷偷来吃残祭 | 院落 / 待拆小庙路径源 |
| **店铺外香火贡品** | 路口店门口香炉：面包作供、烟当香；附身宿主往炉上摆（空祭喂饵） | 第3关路口香炉主钩；面包/烟三阶失败 |
| **路边烧纸** | 纸灰未冷，本地孤魂疯抢 | 拆迁夜 / 路边祭路径高峰 |
| **聚阴古树** | 小区 / 公园 / 学校角落古树聚阴，细祟趴根吸 | 步道 / 学府路侧路径锚 |
| **形似神佛 · 误拜** | 污渍 / 光影 / 雕像像神佛，被当神迹祭拜，**念力汇集**成饵 | 探灵 / 假单等「看起来香其实脏」 |
| **空祭** | 群众自发纪念：有贡品有念力，**目标不在**（人不在场、或不在阳间常理位） | 窗台 / 桥头花束 / 事故点蜡烛 |

**规则**：六类可复用变体，**不要全塞第 1 关**；电梯「看广告」仍只作第 1 关特例。挂关示例见 `03` / `05_levels`（第3香炉空祭、步道古树、槐安神龛、探灵误拜、桂英窗台空祭、拆迁烧纸、假单神迹等）。

### 机位规则（写关必须交代）

玩家始终通过**监控画面**贴符；符位点必须落在**当前可用机位的画面内**。

| 规则 | 说明 |
|---|---|
| **每关写清机位** | 单/多、角度、覆盖范围；塔位表只列「画面内」位点；临时机位须标**稳定 / 不稳** |
| **电梯轿厢默认角** | 摄像头一般在天花板某角 → **俯视约 45°**；门、门下缝、地板、广告屏、按键区、楼层板在画内；轿厢顶检修缝等俯视照不到处，单机位阶段不开放 |
| **机位克制（v4.2）** | 默认**单机位**。多机位仅当明显增加难度或服务剧情；前期能少机制就少 |
| **第 1–4 关：单机位** | 只开一路固定监控；合适但镜头照不到的位点**删掉** |
| **第 5 关：多机位首教（少数例外）** | 可切换监控；须注明为何单路教不清（本关：驱离路与定神交接分属不同覆盖） |
| **第 6 及以后** | **不要为巩固而强开多机位**；教学弧/布丁弧凡可单路改回单路；后期（如第11、23）仅难度/剧情需要再开 |
| **NPC 手机镜头（临时）** | 复杂关可借**单主 / 看守手机**（点名例：**第 11 关**）；接电话/熄屏可掉线；第7不开老韩手机 |
| **不稳机位对策** | 关键塔位仍应落在稳定监控上；手机位只作补盲 / 侦察 / 短时布阵；掉线前半拍预警（来电 UI / 电量红），掉线后该路塔停效或冻结至重连 |
| **越界检查** | 写完塔位后对照**当前仍可用**机位覆盖扫一遍；越界则改位点或推迟到多机位关 |
| **少人原则（v3.8）** | 机位构图尽量少画全身人：优先鬼影、道具、环境、监控噪点；必要人影用剪影 / 局部 / 远端小人。关节多的路人正脸全身能省则省 |

写关自问：这一镜能不能靠香炉、面包、烟、鬼影、路口讲完？能就不堆路人。

### 符能量（替阳光）

**一句话**：符的能量有限，用完消散；**玩家符力条持续自动补充**——基础靠自回，掉落与商店是加速与应急。

| 项 | 定稿 |
|---|---|
| **消耗** | **贴符**一次扣符力；符在位点**持续工作时持续耗能** |
| **耗尽** | 符力归零 → 图标灭、符消散、**塔位空出**，须补贴并再付贴符费用 |
| **基础来源** | **持续自动回复**（关内默认开着，像缓慢回蓝）——**主通道**，不是点缀 |
| **提速** | **天赋**（约第 6 关天赋树后可选「回灵」类）加快自回；**道具**（符力补充、**葫芦**等）短时加速或扩拾取 |
| **掉落 / 应急** | 祟消散掉「符力碎片」、祭品碎屑等飘落物——**加速攒力与一大波应急**，不是唯一来源；商店「符力补充」= 立刻灌一截 |
| **与符纸关系** | 符纸=可贴种类/库存；符力=关内「电量」。有纸没力也贴不上、撑不久 |
| **节奏对标** | 像 PvZ 有阳光经济，但本游**底盘是自回**：布阵时别把条抽干；掉落与葫芦是「多种快一点」，不是「不捡就没得种」 |

教学关（第 1）须明示：**符力条在自己回**；顺带高亮一次祟散掉落（应急糖）。关卡可写「本波自回偏慢 / 掉落偏多」作难度旋钮。

### 符被 NPC / 环境踢掉 / 冲掉

镇守符贴在生活空间里，**会被人与环境弄掉**——不是 Bug，是压力源，逼玩家补贴与补符力。

| 情形 | 示例 | 后果 |
|---|---|---|
| **NPC 踢掉** | 电梯乘客进出踩/踢到**门下缝**的符 | 该塔位空出；符消散（已耗符力不退）；须补贴 |
| **环境冲掉** | 地面积水、门风、井盖回灌、车流擦碰 | 同上；大潮来临前可给「符纸翘角」预警 |
| **设计用途** | 第 1 关门下缝刻意教「人流会踢符」 | 好处：位点好贴、视频内；坏处：要盯人流、准备补贴预算 |

禁止把「踢符」做成无解惩罚：预警半拍 + 补贴窗口足够；教学关踢掉后强制提示一次。

### 浓度与守护目标

- **浓度**：局部祟密度（电梯轿厢、走廊、渠段等）。UI 可用条 / 雾色表示。  
- **守护目标**：具体人或物（室友、香炉供进度、靠窗女孩、老闵交接、成型灵、布丁、小禾惧值/盘踞核、灶台、书桌门窗……）。  
- 失败条件必须**能解释成生活后果**（人冷、人倒、恐慌、魂魄被打碎、成型冲散、惧值破线/梦魇缠上、阳气被啃光……），禁止纯抽象「血条归零」而无说法。手段须打/控/驱**鬼**，符贴在鬼的路径与位点上。

### 一大波节点

每常规关 / Boss 关至少一处「一大波」：例如电梯停 -3、步道人散后啃食高峰、渠底淤翻身、囡囡哭声引潮。教学关可用小波 + 一小大波教扛压。

### 失败与重开（通用）

战斗失败后：

1. **老周劝退**（耳机短句，**人话、口语**，带一点无奈或玩笑，**不是 UI 弹窗**；禁止「行了先撤 / 单就黄了 / 活着才能接」这类跳跃文案）。示例三选一或按关变体：  
   - 「行吧，我也不能对你要求太高……」  
   - 「看来你不太适合这份工作。」  
   - 「今天先到这儿吧，我去问问那谁有没有空。」  
2. 结算界面给两选项：**从本关重开** / **读取进度（回书桌）**。  
3. 不扣主线旗标已写入的长期选择（若本关已处理分支则按存档点规则回滚到关前）。

细则与星级惩罚见各关；本条写进通用规则，各关剧本可复述失败条件，不必重抄劝退流程。

### 场景复用

同一生活场景可再出现：电梯可作复训 / 某关前奏；桥、步道、槐安里院、渠可在中后段变体再战。`03_level_order.md` 表中标注「电梯复用」等。

### 与旧「点消」表述的关系

- **旧稿**：第 1 关曾写「极简点消祟团」作教学。  
- **现稿**：以**贴符塔防**为主；点问号 / 划过热点仍保留（侦察习惯）；路上偶发「点掉飘屑」仅作反馈糖，**不替代布阵与守线**。  
- 文档与关卡文案凡写「点消为主」处，一律改为贴符位点 + 路径 + 守护 / 浓度。

### 通用关卡流程（塔防版）

接单 → **侦察**（逛热点 / 问号，约 1 分钟）→ **布阵**（在机位画面内的塔位点贴镇守符，耗符力）→ **守波**（敌人沿路径走；符力持续自回；捡碎片 / 葫芦吸入；手动画符补刀 / 控场；**可撕符**重组；留意踢符与手机位掉线）→ （有名鬼则）定神后**召唤阴差**或其它**处理** → 结算 → 回书桌。

## 4.1 对标植物大战僵尸的教学节奏

原则：**一关只教会一件「新动手的事」**；旧机制在后续关复用并加一层剧情压力。前段（1–6）刻意更碎、更简单；温情大戏从第 7 关才开始。

| 关 | 像 PvZ 哪一课 | 本关只强调学会的一件事 | 剧情同步给一点 |
|---|---|---|---|
| 1 让人发冷的电梯 | 日间第一片草地：种塔 + 资源条启蒙 | **机位内缝隙贴符** + **符力持续自回**（掉落为辅）+ 浓度 + 扛一小大波；门下缝可被踢 | 乱坟岗小区；鬼渣爱看电梯广告（第1特例）；单机位俯视约 45° |
| 2 热水器 | 第一棵豌豆 + 向日葵 | **镇宅（阵）+ 五雷（手）** | 槐安里、铜铃 |
| 3 路口便利店香炉 | 土豆雷 / 先看清再打 | **显形咒（净眼类）逼附身现形**才能打；面包/烟三阶失败 | 交通摄像头俯视路口；香炉入画；少画路人 |
| 4 末班 404 | 驱离符·改道分区（对标 PvZ 驱离符：改道不伤血） | **驱离符**把善鬼赶到后半节；旁座贴驱离符护靠窗女孩 | 车上一堆善鬼正常坐；到站自下；降灵可轻量后排 |
| 5 按住老闵 | 冰冻生菜 / 改道+按住 | **驱离绕路 + 定神顶住 + 召唤阴差**；**多机位首教（例外）** | 别打碎；马科长 |
| 6 即将成型的灵 | 收集阳光式灌条 + 送走 | **补灵/成型条 + 降灵送投胎主教学**；定神→召唤阴差；**单机位** | 天赋树；芮姐；红皮鞋仅热点 |
| 7 步道 | 大蒜改道 + 按住送走 | **驱离引角 + 撕符 + 定神 + 召唤阴差**；唤阴差/驱散（收服次要） | 布丁（狗）；项圈 |
| 8 狗牌 | 推小车护送 | **轻塔防寻人**；点书包挂饰与三句台词 | 找林小禾；非Boss |
| 9 空车棚 | 清潮巩固关 | **镇守清潮 + 撕符**；影子试探预习 | 非Boss；铺第10 |
| 10 卧室 Boss | **第一次真正 Flag / 首次Boss** | 定神/镇宅/五雷控场+输出 + 禁点 + 铜铃打断 | 林小禾；仅收服助战 |
| 11 囡囡 | 剧情抉择关（少新枪） | **对话三请求**（封印后果）+ 轻塔防清潮 | 反套路起 |
| 12–13 | 车关 / 水路 | 鬼打墙、火符 → 护送+契约 | 小武 |
| 14–15 | 迷雾 / 巨人僵尸 | 分魂双画面 → 淤 Boss + Stroop | 中段反转 |
| 16–17 | 保护坚果墙 | 保护型塔防+**驱离护灶/定神巩固** → 开眼滤镜限时；**第17降灵温情加深** | 桂英听完再送 |
| 18 | 读关卡骗术（前奏复用电梯） | **识破标记** | 假单；**电梯复用** |
| 19–20 | 屋顶 / 保龄 | 夜视多点阵 → 往生符正式 | 拆迁；桥 |
| 21–22 | 看你自己的院子 | Meta 第四面墙 → **书桌布阵** | 救同事；自保 |
| 23–25 | 冒险模式终章拆关 | 速切拘魂 → 真名分支 → 往生大阵 | 终章可玩 |

**节奏口诀（给关卡策划）**

1. 新机制出现的那一关，敌人波次偏少、容错偏高。  
2. 下一关立刻用「旧机制 + 一点剧情压力」考一次，不再塞第二个新枪。  
3. Boss 关优先考「已教组合」，最多加一个表现层（禁点 / Stroop / 双画面）。  
4. 纯抉择关（囡囡三请求）可以几乎不教新符，避免决策疲劳叠操作疲劳；抉择后仍用轻塔防清「哭声引潮」。  
5. 每关写清：**路径逻辑 / 守护目标 / 失败条件 / 一大波 / 机位**。
6. 塔位必须在机位覆盖内；**默认单机位**；第5多机位为例外；6+不为巩固强开多机位。
7. 符力：**自回为主**，掉落/商店/葫芦为加速与应急；关内勿另发明第二套阳光系统。
8. 写关点名一类「祟为何聚」；复杂关可用不稳手机位，关键塔仍靠固定监控。  
9. **少人**：能靠鬼/道具/环境讲完的关，少堆全身路人；影响机位构图。

## 4.1b 教学旁白与生活劝诫（design-v4.0）

> 对标评书 / 林正英气质：**劝人向善、别做傻事**——落在一句旁白或热点上，**不单独开教育关，不打断画符节奏。**  
> **人话带教**：用**老周、小路、芮姐**等人把操作与世界说清楚——像师傅带徒弟，不像念标语。扫各关关键对话：生硬口号、跳跃比喻一律改成口语带教。

### 规则

| 约束 | 说明 |
|---|---|
| **每关最多一句劝诫** | 侦察、老周语音、结算字幕三选一；战斗连点段禁止插长劝诫 |
| **可跳过** | 旁白可点「跳过」；漏听不卡关；后果仍由处理分支记账 |
| **语气** | **口语、人话**；可带一点恐吓感或玩笑（如「晚上别瞎转哦～」）；**禁止**标语口号、跳跃文案（「单就黄了 / 活着才能接」一类）、UI 弹窗「请勿……」 |
| **谁来带** | 优先老周（操作与规矩）、小路（平台话术反面教材）、芮姐（夜班经验）；马科长等可点一句世界观 |
| **与机制挂钩** | 最好落在本关新机制旁：学贴符时说「门下缝也能贴，人进出可能踢掉」；学净眼时说「先看清再动手，别打自己人」 |

### 旁白落点示例（与 `03` 劝诫钩对应）

- 第 1：老周「先别砸。门下面那条缝、门两边——镜头里闪的地方贴上去。符力条自己会回；人进出可能把符踢飞，盯着补贴。」  
- 第 2：老周「看清亮的顺序，一笔下去。符在屏幕上，不在纸上。——合租也别半夜瞎转卫生间。」  
- 第 3：老周「先显形。附身没现出来你打谁？——香炉上那块面包不是他买着玩的，别让他摆满三块、点满三只烟。」  
- 第 4：老周「车上好多都是善鬼，正常坐车。贴驱离符，把它们赶到后头；女孩旁边那座椅贴一张就行。」  
- 第 5：马科长「阴差晚一会儿。驱离让他绕，定神顶住——别打碎。碎的东西不会没，只会往低处流。」  
- 第 6：老周「碎片往圈里送，定神稳住，窗口一开送去投胎。」  
- 第 7：**必用**「晚上不要在小区瞎转哦～」；带教驱离引角+撕符+唤阴差  
- 第 9：老周「空车棚里没人。你打的是影子和细祟——符是打鬼的。」  
- 第 10：老周「符贴在鬼的路径与位点上。顶住那团盘踞的，打散它。铜铃断蓄力。」  
- 第 12：小武「还有四分钟」→ 老秦/你可接「命比准时率贵」。  
- 第 14：苏芮「撤，渠底有东西」→ 劝诫「别为直播下渠」。  
- 第 15：反转课「驱散是拆成饲料」= 反劝善总账，可略长，但仍是剧情不是弹窗。

### 驱鬼者 = 秩序一侧（玩法侧读法）

- 报阴 / 往生 / **降灵入轮回** / 收服 / 留灯：走「警察把人送回家」隐喻——中等或零即时收入，旗标与结局回报。  
- 驱散：走「只认罚单金额」隐喻——小路加价，杀孽与淤/千怨变强。  
- 商店与星级**不**因向善而锁死；道德与金钱分轨（见 4.5）。

## 4.1c 处理类型补「降灵入轮回」（design-v4.0）

完整对照表见 `01` §2.3。玩法侧只补一句：

| 方式 | 你在干什么 | 通道 | 挂关 |
|---|---|---|---|

### 硬原则与符箓实战补丁（v4.2 定稿）

| 原则 | 定稿规则 |
|---|---|
| **符贴环境对鬼生效** | 符只能贴在屋内/环境位置上（门框、门缝、窗台、走廊地面、灶台等固定空间位点），形成阳气结界阻挡或改道，对经过的鬼祟起效；非附身状态绝不可往活人身上乱贴。 |
| **唯附身贴人身** | 唯独活人被「附身」时（如第3关便利店醉汉），显形咒/清心符才允许贴在活人身体上（后颈、额头），逼出体内阴煞。 |
| **五雷地掷引雷** | 五雷符等攻击符不需要往鬼身上硬贴，选中地面扔下去引天雷落地，引天火雷光炸碎阴气。 |
| **撕符** | 任意已贴符可手动撕掉 → 位点空出、效果打断；用于把有名魂与祟团分开、重组阵型。 |
| **定神→召唤阴差** | 定神顶住后 UI **召唤阴差**；阴差只收**完整/有名魂**；普通祟团无效或马科长拒收。布丁奈何桥舍身逆冲返阳救主。 |
| **机位克制** | 默认单机位；多机位须有难度或剧情理由；第5为例外首教；第6+不为巩固强开。 |

第 1 关镇守为**缝隙贴符教学版**（自动对准缝、持续掉血），第 2 关起正式「镇宅」命名与布阵 UI。

## 4.3 环境交互系统（热点 / 问号 / 划过）

### 目的

养成玩家 **「进关先逛一圈」** 的习惯，便于日后插入情节道具、线索、脑补掉落，而不显得「任务箭头突然出现」。

### 规则（师傅端侦察阶段 + 轻度战斗中）

| 交互 | 操作 | 反馈 | 设计约束 |
|---|---|---|---|
| **问号热点** | 点击画面上的 `?` 或微光轮廓 | 弹出 1–3 句说明 / 老周吐槽 / 单主备注补充 | 第 1 关强制教一次；之后每关 1–2 个有 mechan 价值，其余可纯风味 |
| **鼠标划过热点** | 光标滑过门缝、井盖、狗牌、香炉等 | 描边高亮 + 短 tooltip（不必点开） | 移动端改为「长按预览」或「轻触闪一下再点」 |
| **可收取物** | 点高亮小物件 | 进「侦察笔记」或直接进背包（脑补掉落） | **无完整支线**；最多解锁一句日后对白或商店折扣彩蛋 |
| **危险误点** | 点错「看起来像线索其实是祟团诱饵」 | 小惊吓（无跳吓）：黑丝一闪、评分不扣或微扣 | 每关最多 1 个，避免惩罚探索 |

### UX 原则

- 侦察限时约 45–90 秒，但**不因漏点热点而卡关**；漏了只少风味与掉落。  
- 关键剧情线索（狗牌、红皮鞋、香炉）除热点外，过场镜头也会扫到一次，防止「没点到就剧情断」。  
- 养成后：假单关（第 18）的「标记可疑」就是同一套肌肉记忆的进阶。  
- **劝诫可挂在热点上**：点开只多半句老周吐槽（如井盖「别凑热闹」），不强制阅读。

### 每关热点数量建议

短教学关 **2–3**；常规关 **3–4**；Boss / 终章 **2–4**（战斗中热点减少，避免干扰画符）。

> 各关具体 2–4 个例子写在 `05_levels/` 对应剧本的「可交互热点」或侦察小节。每关剧本另可写一行「关键对话 / 劝诫钩」。

## 4.5 书桌经济与商店

### 经济节奏

- **开局一穷二白**：序章结束金币 ≈ 0；第 1–2 关报酬低（几十到一百级）。  
- 金币用途必须明确，否则「钱没用」。本作用途：**书桌商店** + 少量关前「多带一张符」临时购买。  
- **星级故意不影响结局**（保留 v2）；小路会嘲讽低星，但不锁主线。  
- 功德 / 杀孽走剧情与结局；金币走便利与表现。——**道德与金钱分轨**：向善不罚你穷，贪驱散也不因买满商店而洗白（坏结局 C 不因买满避免）。

### 商店入口

主界面书桌 → 点击「平台商城 / 旧货架」窗口（小路语音导购，可静音）。

- 坏结局 C 不因买满商店而避免；经济与道德分轨。  
- **葫芦**：不改变自回底盘，只让场上飘落物更好捡；无葫芦仍可靠自回通关，中后波密关体感更从容。

## 4.6 护身物（开局三问）

序章由老周**三问**写入旗标（非五项平铺菜单），详见 `05_levels/00_prologue.md`。

| 旗标取值 | 对应三问结果 | 对话气质 | 可选轻量加成（非正式硬核） |
|---|---|---|---|
| `随身物` | 第 1 问选「有」（长命锁 / 佛珠 / 护身符一类） | 老周少吐槽；「长辈看着呢」感 | 镇守持续时间 +5%，或首次擦伤免一星 |
| `外国神物` | 第 2 问选「有」（十字架 / 御守一类） | 马科长偶尔愣一下；小路敬语多半句 | 假单/借面可疑点微加亮，或定神持续时间微增 |
| `baifo.life观音` | 第 3 问（前两问都「没有」；可外链彩蛋） | 老周：「凑合一下」；点击可再开站点 | 无硬加成 / 或极微随机 |

第 22 关「你家」：点击护身物可释放一次「安心」护盾。关闭数值附录不影响通关。  
**劝善读法**：护身物是「我还是活人」的锚——序章老周已点明；不是伤害数值，是守夜的人需要的气味。

## 4.7 通用关卡流程（提醒）
