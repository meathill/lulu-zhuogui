# 04 · 玩法 · 教学曲线 · 经济 · 交互 · 掉落

> design-v3.1 ｜ 落实反馈：PvZ 式节奏、环境交互、脑补掉落、书桌商店；教学旁白可带**轻微生活劝诫**（不打断节奏）。

## 4.1 对标植物大战僵尸的教学节奏

原则：**一关只教会一件「新动手的事」**；旧机制在后续关复用并加一层剧情压力。前段（1–6）刻意更碎、更简单；温情大戏从第 7 关才开始。

| 关 | 像 PvZ 哪一课 | 本关只强调学会的一件事 | 剧情同步给一点 |
|---|---|---|---|
| 1 电梯 | 日间向日葵前的「点僵尸头」 | **点问号 / 划过热点** + 极简点消 | 生活场景开场 |
| 2 热水器 | 第一棵豌豆 + 向日葵 | **镇宅（阵）+ 五雷（手）** | 槐安里、铜铃 |
| 3 便利店 | 土豆雷 / 别打自己人 | **净眼 → 再打附身**；糯米挡路 | 井口伏笔 |
| 4 末班 404 | 双发射手 + 第一次选关卡目标 | **八卦改道 + 引魂灯**；四种处理 UI | 周阿婆；狗牌预埋 |
| 5 夜巡科 | 冰冻生菜 / 传送带教学 | **定身 + 一键报阴** | 祟团生态课 |
| 6 安神 | 催眠蘑菇轻量版 | **安神符 + 铜铃打断蓄力** | 红皮鞋；芮姐 |
| 7 步道 | 第一次「有名字的植物剧情」 | **有名鬼的处理分支**；阳气视觉 | 布丁初见 |
| 8 狗牌 | 推小车护送 | **轻护送**（无新符） | 找小禾 |
| 9 卧室 Boss | 第一次真正 Flag 关 | **Boss 禁点 + 入梦** | 布丁决战 |
| 10 囡囡 | 剧情抉择关（少新枪） | **对话三请求**（封印后果） | 反套路起 |
| 11–12 | 车关 / 水路 | 鬼打墙、火符 → 护送+契约 | 小武 |
| 13–14 | 迷雾 / 巨人僵尸 | 分魂双画面 → 淤 Boss + Stroop | 中段反转 |
| 15–16 | 保护坚果墙 | 保护型塔防 → 开眼滤镜限时 | 桂英 |
| 17 | 读关卡骗术 | **识破标记** | 假单 |
| 18–19 | 屋顶 / 保龄 | 夜视多点阵 → 往生符正式 | 拆迁；桥 |
| 20–21 | 看你自己的院子 | Meta 第四面墙 → **书桌布阵** | 救同事；自保 |
| 22–24 | 冒险模式终章拆关 | 速切拘魂 → 真名分支 → 往生大阵 | 终章可玩 |

**节奏口诀（给关卡策划）**

1. 新机制出现的那一关，敌人波次偏少、容错偏高。  
2. 下一关立刻用「旧机制 + 一点剧情压力」考一次，不再塞第二个新枪。  
3. Boss 关优先考「已教组合」，最多加一个表现层（禁点 / Stroop / 双画面）。  
4. 纯抉择关（囡囡三请求）可以几乎不教新符，避免决策疲劳叠操作疲劳。

## 4.1b 教学旁白与生活劝诫（design-v3.1）

> 对标评书 / 林正英气质：**劝人向善、别做傻事**——落在一句旁白或热点上，**不单独开教育关，不打断画符节奏。**

### 规则

| 约束 | 说明 |
|---|---|
| **每关最多一句** | 侦察、老周语音、结算字幕三选一；战斗连点段禁止插长劝诫 |
| **可跳过** | 旁白可点「跳过」；漏听不卡关；后果仍由处理分支记账 |
| **语气** | 恐吓感 + 半句玩笑，像「晚上别瞎转哦～」；禁止标语口号、禁止 UI 弹窗「请勿……」 |
| **与机制挂钩** | 最好落在本关新机制旁：学侦察时说人少处别夜游；学四种处理时说听完比打碎贵 |

### 旁白落点示例（与 `03` 劝诫钩对应）

- 第 1：老周「晚上电梯最爱停的地方……别逞能夜游。」  
- 第 3：醉汉清醒「下午多看了一眼那口井」→ 结算可闪「井口别凑热闹」。  
- 第 4：老周「选之前想三秒。」（四种处理 = 劝善入口）  
- 第 5：马科长「碎的东西不会没，只会往低处流。」  
- 第 7：**必用**「晚上不要在小区瞎转哦～」  
- 第 11：小武「还有四分钟」→ 老秦/你可接「命比准时率贵」。  
- 第 13：苏芮「撤，渠底有东西」→ 劝诫「别为直播下渠」。  
- 第 14：反转课「驱散是拆成饲料」= 反劝善总账，可略长，但仍是剧情不是弹窗。

### 驱鬼者 = 秩序一侧（玩法侧读法）

- 报阴 / 往生 / 约定 / 留灯：走「警察把人送回家」隐喻——中等或零即时收入，旗标与结局回报。  
- 驱散：走「只认罚单金额」隐喻——小路加价，杀孽与淤/千怨变强。  
- 商店与星级**不**因向善而锁死；道德与金钱分轨（见 4.5）。

## 4.2 四类符（解锁概览）

| 类 | 代表 | 约解锁关 | 用途一句话 |
|---|---|---|---|
| **镇守** | 镇宅、八卦、引魂灯 | 2、4 | 贴在监控画面里挡路 / 改道 / 指路 |
| **攻击** | 五雷、定身、火符 | 2、5、11 | 连点成符砸向目标 |
| **功能** | 净眼、安神、分魂、开眼滤镜 | 3、6、13、16 | 看见、安神、分屏、让活人短暂见鬼 |
| **仪式** | 契约、往生（借/正式）、拘魂、往生大阵 | 12、19、22、24 | 剧情向；改变处理结局 |

画符点阵默认 4–7 点；Boss 可达 9 点并出现红色禁点。口诀收尾：「急急如律令」。

## 4.3 环境交互系统（热点 / 问号 / 划过）

### 目的

养成玩家 **「进关先逛一圈」** 的习惯，便于日后插入情节道具、线索、脑补掉落，而不显得「任务箭头突然出现」。

### 规则（师傅端侦察阶段 + 轻度战斗中）

| 交互 | 操作 | 反馈 | 设计约束 |
|---|---|---|---|
| **问号热点** | 点击画面上的 `?` 或微光轮廓 | 弹出 1–3 句说明 / 老周吐槽 / 单主备注补充 | 第 1 关强制教一次；之后每关 1–2 个有 mechan 价值，其余可纯风味 |
| **鼠标划过热点** | 光标滑过门缝、井盖、狗牌、香炉等 | 描边高亮 + 短 tooltip（不必点开） | 移动端改为「长按预览」或「轻触闪一下再点」 |
| **可收取物** | 点高亮小物件 | 进「侦察笔记」或直接进背包（脑补掉落） | **无完整支线**；最多解锁一句日后对白或商店折扣彩蛋 |
| **危险误点** | 点错「看起来像线索其实是祟团诱饵」 | 小惊吓（无跳吓）：黑丝一闪、评分不扣或微扣 | 每关最多 1 个，避免惩罚探索 |

### UX 原则

- 侦察限时约 45–90 秒，但**不因漏点热点而卡关**；漏了只少风味与掉落。  
- 关键剧情线索（狗牌、红皮鞋、香炉）除热点外，过场镜头也会扫到一次，防止「没点到就剧情断」。  
- 养成后：假单关（第 17）的「标记可疑」就是同一套肌肉记忆的进阶。  
- **劝诫可挂在热点上**：点开只多半句老周吐槽（如井盖「别凑热闹」），不强制阅读。

### 每关热点数量建议

短教学关 **2–3**；常规关 **3–4**；Boss / 终章 **2–4**（战斗中热点减少，避免干扰画符）。

> 各关具体 2–4 个例子写在 `05_levels/` 对应剧本的「可交互热点示例」小节。每关剧本另可写一行「生活劝诫可出现处」。

## 4.4 脑补掉落（短描述物件）

**定义**：侦察或结算时获得的短描述物件。**没有完整支线**，不打开新地图；玩家可自行脑补故事。图鉴里归类为「拾遗」。

### 掉落表示例（12 件）

| ID | 物件 | 短描述（图鉴原文方向） | 约出现 |
|---|---|---|---|
| D01 | 半截冰棍棍 | 圆珠笔写了个「布」。土是松的。有人认真埋过什么。 | 7 |
| D02 | 泡烂的五星贴纸 | 外卖箱上撕下来的。星星还在，单已经超时一年。 | 11 |
| D03 | 未燃尽的香灰 | 三根。掐灭的手法很稳，像每月初一都来的人。 | 10 / 16 |
| D04 | 旧式纸车票 | 站名「槐安里」还印着。现在线路图上那一站被贴纸盖住了。 | 4（送行） |
| D05 | 儿童红绳一根 | 很短。不像大人的手链。线头是咬断的。 | 10（受骗≥1） |
| D06 | 关东煮竹签 | 便利店价签 2 元。竹签上有齿痕——不是人的。 | 3 |
| D07 | 电梯广告贴纸角 | 「夜间兼职眼睛干净」。你自己也点过类似的。 | 1 |
| D08 | 生锈铜铃碎片 | 声音你听过。整只铃还在槐神龛檐角上。 | 2 / 10 |
| D09 | 空白工单截图 | 平台显示「账号注销」。单号位是空的。谁查过？ | 13（芮姐相关） |
| D10 | 校服校徽扣 | 学府中学。背面刻了个「禾」字，很浅。 | 8 |
| D11 | 煤气灶旋钮橡胶垫 | 旋到「关」的位置有道磨痕，比「开」深得多。 | 15 |

**规则**

- 掉落进图鉴即可；**不强制**打开阅读。  
- 允许 1–2 件在终章被老周或苏芮「多看一眼」提一句，形成轻回收，仍不算支线。  
- 驱散有名鬼时，对应掉落可变灰或加一行：「碎了。只剩这个。」——**劝善记账的静物版。**

## 4.5 书桌经济与商店

### 经济节奏

- **开局一穷二白**：序章结束金币 ≈ 0；第 1–2 关报酬低（几十到一百级）。  
- 金币用途必须明确，否则「钱没用」。本作用途：**书桌商店** + 少量关前「多带一张符」临时购买。  
- **星级故意不影响结局**（保留 v2）；小路会嘲讽低星，但不锁主线。  
- 功德 / 杀孽走剧情与结局；金币走便利与表现。——**道德与金钱分轨**：向善不罚你穷，贪驱散也不因买满商店而洗白（坏结局 C 不因买满避免）。

### 商店入口

主界面书桌 → 点击「平台商城 / 旧货架」窗口（小路语音导购，可静音）。

| 分类 | 商品 | 约价（草案） | 效果 | 解锁条件 |
|---|---|---|---|---|
| **摄像头升级** | 标清→高清镜头 | 120 | 侦察更清晰；符力衰减略减 | 第 2 关后 |
| | 多路切换卡 | 200 | 同时盯 2 路不卡顿 | 第 5 关后 |

| | 黑狗血×1 | 80 | 暂凝淤类部位 | 第 14 前可囤 1 |

### 设计注意

- 商店**不卖**通关必需的关键剧情道具（狗牌、开眼、往生授权）。  
- 贵重升级在终章前买满应花费大约「认真玩但不刷」的总收入的 40–60%，留下「还可以再接一单」的感觉。  
- 坏结局 C 不因买满商店而避免；经济与道德分轨。  
- 小路导购若推「驱散加成包」类商品——**不要进货架**；避免把反劝善对照做成可购买优势。

## 4.6 护身物（开局三问）

序章由老周**三问**写入旗标（非五项平铺菜单），详见 `05_levels/00_prologue.md`。

| 旗标取值 | 对应三问结果 | 对话气质 | 可选轻量加成（非正式硬核） |
|---|---|---|---|
| `随身物` | 第 1 问选「有」（长命锁 / 佛珠 / 护身符一类） | 老周少吐槽；「长辈看着呢」感 | 镇守持续时间 +5%，或首次擦伤免一星 |
| `外国神物` | 第 2 问选「有」（十字架 / 御守一类） | 马科长偶尔愣一下；小路敬语多半句 | 假单/借面可疑点微加亮，或安神冷却微减 |
| `baifo.life观音` | 第 3 问（前两问都「没有」；可外链彩蛋） | 老周：「凑合一下」；点击可再开站点 | 无硬加成 / 或极微随机 |

第 21 关「你家」：点击护身物可释放一次「安心」护盾。关闭数值附录不影响通关。  
**劝善读法**：护身物是「我还是活人」的锚——序章老周已点明；不是伤害数值，是守夜的人需要的气味。

## 4.7 通用关卡流程（提醒）

接单 → **侦察**（逛热点 / 问号，约 1 分钟）→ 布阵（镇守符）→ 战斗（画符）→ **处理** → 结算（金币 / 功德 / 星级 / 可能掉落）→ 回书桌（可逛商店）。

订单文案 = App 内显示；单主备注 = 客户手写感。`{玩家名}` / `{称呼}` 随创建替换。

处理阶段是**劝善记账入口**：同一 UI，四种结果；小路推驱散高亮，老周可在耳机里哼一声（可关）——玩家听不听随你。
