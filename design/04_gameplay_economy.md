## 4.0 塔防总则

### 一句话

**贴符 = 种塔**；祟 / 鬼沿**说得通的路径**走向**守护目标**；浓度或目标破线即失败。点消只作极轻辅助（如路上的飘屑），**不以点消为主玩法**。

### 核心对照

| 塔防概念 | 本游对应 |
|---|---|
| 塔 | **符位**：镇守符贴在缝隙 / 路口 / 门窗等固定位点，持续对路径上的祟生效 |
| 手操攻击 | **五雷等攻击符**：连点成符砸向高威胁目标 / Boss；补塔力不足的瞬间 |
| 敌人路径 | 祟团 / 有名鬼沿地图路线移动；路线须有**生活逻辑**（见下） |
| 守护目标 | 活人阳气、电梯浓度、安神条、护送单位、灶台、书桌等 |
| 资源 | **符力**（关内主资源，替 PvZ 阳光）、符纸、糯米、铜铃次数、关前商店补给 |
| 一大波 | 关内至少一个「浓度骤升 / 路径变长 / Boss 入场」节点（旗标波） |

### 路径逻辑（写关必须交代）

路线不是抽象格子，要能用一句话解释「为什么鬼往那儿走」：

- **小区夜路**：人散后阳气碎渣浮在步道上，祟团来啃。  
- **电梯**：鬼渣爱聚电梯里看广告，从门缝、门下缝、电缆井、楼层缝往轿厢聚（入口须落在机位画面内，见下）。  
- **地漏 / 井盖**：往低处、往宿主阳气、往怨脉汇。  
- **公交车厢**：找活人座 / 执念目标（阿婆找站）。  
- **梦境**：怕与执念铺成的巷子接到卧室。

### 机位规则（写关必须交代）

玩家始终通过**监控画面**贴符；符位点必须落在**当前可用机位的画面内**。

| 规则 | 说明 |
|---|---|
| **每关写清机位** | 单/多、角度、覆盖范围；塔位表只列「画面内」位点 |
| **电梯轿厢默认角** | 摄像头一般在天花板某角 → **俯视约 45°**；门、门下缝、地板、广告屏、按键区、楼层板在画内；轿厢顶检修缝等俯视照不到处，单机位阶段不开放 |
| **第 1–4 关：单机位** | 只开一路；合适但镜头照不到的位点**删掉**，或标「需多机位、第 5 关后才可用」 |
| **第 5 关起：可多机位** | 可切换监控；第 5–6 关教学切换；后期速切（如第 22）在此基础上加压 |
| **越界检查** | 写完塔位后对照机位覆盖扫一遍；越界则改位点或推迟到多机位关 |

### 符能量（替阳光）

**一句话**：符的能量有限，用完消散，玩家须不停补充——**替代 PvZ 收集阳光**。

| 项 | 定稿 |
|---|---|
| **消耗** | **贴符**一次扣符力；符在位点**持续工作时持续耗能** |
| **耗尽** | 符力归零 → 图标灭、符消散、**塔位空出**，须补贴并再付贴符费用 |
| **来源（默认）** | **祟消散掉「符力碎片」** + **关内少量自然回复**；商店可买「符力补充」 |
| **备选（未采用）** | 守住波次整波掉符力包——若日后手感偏紧可再开，本稿按默认 |
| **与符纸关系** | 符纸=可贴种类/库存；符力=关内「电量」。有纸没力也贴不上、撑不久 |
| **节奏对标** | 像 PvZ 要不停种向日葵 / 捡阳光——本游要盯消散掉落与自然回复，别只布阵不攒力 |

关卡剧本波次里可写「本波掉符力碎片偏多/偏少」；教学关（第 1）须明示碎片高亮与自然回复提示一次。

### 符被 NPC / 环境踢掉 / 冲掉

镇守符贴在生活空间里，**会被人与环境弄掉**——不是 Bug，是压力源，逼玩家补贴与补符力。

| 情形 | 示例 | 后果 |
|---|---|---|
| **NPC 踢掉** | 电梯乘客进出踩/踢到**门下缝**的符 | 该塔位空出；符消散（已耗符力不退）；须补贴 |
| **环境冲掉** | 地面积水、门风、井盖回灌、车流擦碰 | 同上；大潮来临前可给「符纸翘角」预警 |
| **设计用途** | 第 1 关门下缝刻意教「人流会踢符」 | 好处：位点好贴、视频内；坏处：要盯人流、准备补贴预算 |

禁止把「踢符」做成无解惩罚：预警半拍 + 补贴窗口足够；教学关踢掉后强制提示一次。

### 浓度与守护目标

- **浓度**：局部祟密度（电梯轿厢、走廊、渠段等）。UI 可用条 / 雾色表示。  
- **守护目标**：具体人或物（室友、店员、阿婆、布丁、小禾安神条、灶台、书桌门窗……）。  
- 失败条件必须**能解释成生活后果**（人冷、人倒、恐慌、安神破、阳气被啃光……），禁止纯抽象「血条归零」而无说法。

### 一大波节点

每常规关 / Boss 关至少一处「一大波」：例如电梯停 -3、步道人散后啃食高峰、渠底淤翻身、囡囡哭声引潮。教学关可用小波 + 一小大波教扛压。

### 失败与重开（通用）

战斗失败后：

1. **老周劝退**（耳机短句，恐吓感 + 半句玩笑，**不是 UI 弹窗**）：例如「行了，先撤。人冷过三回，单就黄了。——夜里有的是单，活着才能接。」  
2. 结算界面给两选项：**从本关重开** / **读取进度（回书桌）**。  
3. 不扣主线旗标已写入的长期选择（若本关已处理分支则按存档点规则回滚到关前）。

细则与星级惩罚见各关；本条写进通用规则，各关剧本可复述失败条件，不必重抄劝退流程。

### 场景复用

同一生活场景可再出现：电梯可作复训 / 某关前奏；桥、步道、槐安里院、渠可在中后段变体再战。`03_level_order.md` 表中标注「电梯复用」等。

### 与旧「点消」表述的关系

- **旧稿**：第 1 关曾写「极简点消祟团」作教学。  
- **现稿**：以**贴符塔防**为主；点问号 / 划过热点仍保留（侦察习惯）；路上偶发「点掉飘屑」仅作反馈糖，**不替代布阵与守线**。  
- 文档与关卡文案凡写「点消为主」处，一律改为贴符位点 + 路径 + 守护 / 浓度。

### 通用关卡流程（塔防版）

接单 → **侦察**（逛热点 / 问号，约 1 分钟）→ **布阵**（在机位画面内的塔位点贴镇守符，耗符力）→ **守波**（敌人沿路径走；捡符力碎片 / 自然回复；手动画符补刀 / 控场；留意踢符）→ （有名鬼则）**处理** → 结算 → 回书桌。

## 4.1 对标植物大战僵尸的教学节奏

原则：**一关只教会一件「新动手的事」**；旧机制在后续关复用并加一层剧情压力。前段（1–6）刻意更碎、更简单；温情大戏从第 7 关才开始。

| 关 | 像 PvZ 哪一课 | 本关只强调学会的一件事 | 剧情同步给一点 |
|---|---|---|---|
| 1 让人发冷的电梯 | 日间第一片草地：种向日葵前的「沿路放豌豆」+ 捡阳光启蒙 | **机位内缝隙贴符** + **符力（替阳光）** + 浓度 + 扛一小大波；门下缝可被踢 | 乱坟岗小区；鬼渣爱看电梯广告；单机位俯视约 45° |
| 2 热水器 | 第一棵豌豆 + 向日葵 | **镇宅（阵）+ 五雷（手）** | 槐安里、铜铃 |
| 3 便利店 | 土豆雷 / 别打自己人 | **净眼 → 再打附身**；糯米挡路 | 井口伏笔 |
| 4 末班 404 | 双发射手 + 第一次选关卡目标 | **八卦改道 + 引魂灯**；四种处理 UI | 周阿婆；狗牌预埋 |
| 5 夜巡科 | 冰冻生菜 / 传送带教学 | **定身 + 一键报阴**；**多机位切换**首教 | 祟团生态课 |
| 6 安神 | 催眠蘑菇轻量版 | **安神符 + 铜铃**；多机位巩固（现实/梦层叠化） | 红皮鞋；芮姐 |
| 7 步道 | 第一次「有名字的植物剧情」 | **有名鬼的处理分支**；阳气视觉 | 布丁初见 |
| 8 狗牌 | 推小车护送 | **轻护送**（无新符） | 找小禾 |
| 9 卧室 Boss | 第一次真正 Flag 关 | **Boss 禁点 + 入梦** | 布丁决战 |
| 10 囡囡 | 剧情抉择关（少新枪） | **对话三请求**（封印后果）+ 轻塔防清潮 | 反套路起 |
| 11–12 | 车关 / 水路 | 鬼打墙、火符 → 护送+契约 | 小武 |
| 13–14 | 迷雾 / 巨人僵尸 | 分魂双画面 → 淤 Boss + Stroop | 中段反转 |
| 15–16 | 保护坚果墙 | 保护型塔防 → 开眼滤镜限时 | 桂英 |
| 17 | 读关卡骗术（前奏复用电梯） | **识破标记** | 假单；**电梯复用** |
| 18–19 | 屋顶 / 保龄 | 夜视多点阵 → 往生符正式 | 拆迁；桥 |
| 20–21 | 看你自己的院子 | Meta 第四面墙 → **书桌布阵** | 救同事；自保 |
| 22–24 | 冒险模式终章拆关 | 速切拘魂 → 真名分支 → 往生大阵 | 终章可玩 |

**节奏口诀（给关卡策划）**

1. 新机制出现的那一关，敌人波次偏少、容错偏高。  
2. 下一关立刻用「旧机制 + 一点剧情压力」考一次，不再塞第二个新枪。  
3. Boss 关优先考「已教组合」，最多加一个表现层（禁点 / Stroop / 双画面）。  
4. 纯抉择关（囡囡三请求）可以几乎不教新符，避免决策疲劳叠操作疲劳；抉择后仍用轻塔防清「哭声引潮」。  
5. 每关写清：**路径逻辑 / 守护目标 / 失败条件 / 一大波 / 机位**。
6. 塔位必须在机位覆盖内；1–4 单机位；5+ 可多机位。
7. 符力来源与消耗按 §4.0 默认；关内勿另发明第二套阳光系统。

## 4.1b 教学旁白与生活劝诫（design-v3.1）

> 对标评书 / 林正英气质：**劝人向善、别做傻事**——落在一句旁白或热点上，**不单独开教育关，不打断画符节奏。**

### 规则

| 约束 | 说明 |
|---|---|
| **每关最多一句** | 侦察、老周语音、结算字幕三选一；战斗连点段禁止插长劝诫 |
| **可跳过** | 旁白可点「跳过」；漏听不卡关；后果仍由处理分支记账 |
| **语气** | 恐吓感 + 半句玩笑，像「晚上别瞎转哦～」；禁止标语口号、禁止 UI 弹窗「请勿……」 |
| **与机制挂钩** | 最好落在本关新机制旁：学贴符缝隙时说电梯爱聚鬼渣；学四种处理时说听完比打碎贵 |

### 旁白落点示例（与 `03` 劝诫钩对应）

- 第 1：老周「鬼渣爱在电梯里看广告……门下缝也能贴，人进出可能踢掉，盯着补贴；祟散了会掉符力碎片。」  
- 第 3：醉汉清醒「下午多看了一眼那口井」→ 结算可闪「井口别凑热闹」。  
- 第 4：老周「选之前想三秒。」（四种处理 = 劝善入口）  
- 第 5：马科长「碎的东西不会没，只会往低处流。」  
- 第 7：**必用**「晚上不要在小区瞎转哦～」  
- 第 11：小武「还有四分钟」→ 老秦/你可接「命比准时率贵」。  
- 第 13：苏芮「撤，渠底有东西」→ 劝诫「别为直播下渠」。  
- 第 14：反转课「驱散是拆成饲料」= 反劝善总账，可略长，但仍是剧情不是弹窗。

### 驱鬼者 = 秩序一侧（玩法侧读法）

- 报阴 / 往生 / 约定 / 留灯：走「警察把人送回家」隐喻——中等或零即时收入，旗标与结局回报。  
- 驱散：走「只认罚单金额」隐喻——小路加价，杀孽与淤/千怨变强。  
- 商店与星级**不**因向善而锁死；道德与金钱分轨（见 4.5）。

## 4.2 四类符（解锁概览）

| 类 | 代表 | 约解锁关 | 用途一句话 |
|---|---|---|---|
| **镇守** | 镇宅、八卦、引魂灯 | 1（缝隙练习符）、2、4 | 贴在监控画面里的**塔位点**：挡路 / 改道 / 对路径持续掉血 |

## 4.3 环境交互系统（热点 / 问号 / 划过）

### 目的

养成玩家 **「进关先逛一圈」** 的习惯，便于日后插入情节道具、线索、脑补掉落，而不显得「任务箭头突然出现」。

### 规则（师傅端侦察阶段 + 轻度战斗中）

| 交互 | 操作 | 反馈 | 设计约束 |
|---|---|---|---|
| **问号热点** | 点击画面上的 `?` 或微光轮廓 | 弹出 1–3 句说明 / 老周吐槽 / 单主备注补充 | 第 1 关强制教一次；之后每关 1–2 个有 mechan 价值，其余可纯风味 |
| **鼠标划过热点** | 光标滑过门缝、井盖、狗牌、香炉等 | 描边高亮 + 短 tooltip（不必点开） | 移动端改为「长按预览」或「轻触闪一下再点」 |
| **可收取物** | 点高亮小物件 | 进「侦察笔记」或直接进背包（脑补掉落） | **无完整支线**；最多解锁一句日后对白或商店折扣彩蛋 |
| **危险误点** | 点错「看起来像线索其实是祟团诱饵」 | 小惊吓（无跳吓）：黑丝一闪、评分不扣或微扣 | 每关最多 1 个，避免惩罚探索 |

### UX 原则

- 侦察限时约 45–90 秒，但**不因漏点热点而卡关**；漏了只少风味与掉落。  
- 关键剧情线索（狗牌、红皮鞋、香炉）除热点外，过场镜头也会扫到一次，防止「没点到就剧情断」。  
- 养成后：假单关（第 17）的「标记可疑」就是同一套肌肉记忆的进阶。  
- **劝诫可挂在热点上**：点开只多半句老周吐槽（如井盖「别凑热闹」），不强制阅读。

### 每关热点数量建议

短教学关 **2–3**；常规关 **3–4**；Boss / 终章 **2–4**（战斗中热点减少，避免干扰画符）。

> 各关具体 2–4 个例子写在 `05_levels/` 对应剧本的「可交互热点」或侦察小节。每关剧本另可写一行「关键对话 / 劝诫钩」。

## 4.4 脑补掉落（短描述物件）

**定义**：侦察或结算时获得的短描述物件。**没有完整支线**，不打开新地图；玩家可自行脑补故事。图鉴里归类为「拾遗」。

### 掉落表示例（12 件）

| ID | 物件 | 短描述（图鉴原文方向） | 约出现 |
|---|---|---|---|
| D01 | 半截冰棍棍 | 圆珠笔写了个「布」。土是松的。有人认真埋过什么。 | 7 |
| D02 | 泡烂的五星贴纸 | 外卖箱上撕下来的。星星还在，单已经超时一年。 | 11 |
| D03 | 未燃尽的香灰 | 三根。掐灭的手法很稳，像每月初一都来的人。 | 10 / 16 |
| D04 | 旧式纸车票 | 站名「槐安里」还印着。现在线路图上那一站被贴纸盖住了。 | 4（送行） |
| D05 | 儿童红绳一根 | 很短。不像大人的手链。线头是咬断的。 | 10（受骗≥1） |
| D06 | 关东煮竹签 | 便利店价签 2 元。竹签上有齿痕——不是人的。 | 3 |

## 4.5 书桌经济与商店

### 经济节奏

- **开局一穷二白**：序章结束金币 ≈ 0；第 1–2 关报酬低（几十到一百级）。  
- 金币用途必须明确，否则「钱没用」。本作用途：**书桌商店** + 少量关前「多带一张符」临时购买。  
- **星级故意不影响结局**（保留 v2）；小路会嘲讽低星，但不锁主线。  
- 功德 / 杀孽走剧情与结局；金币走便利与表现。——**道德与金钱分轨**：向善不罚你穷，贪驱散也不因买满商店而洗白（坏结局 C 不因买满避免）。

## 4.6 护身物（开局三问）

序章由老周**三问**写入旗标（非五项平铺菜单），详见 `05_levels/00_prologue.md`。

| 旗标取值 | 对应三问结果 | 对话气质 | 可选轻量加成（非正式硬核） |
|---|---|---|---|
| `随身物` | 第 1 问选「有」（长命锁 / 佛珠 / 护身符一类） | 老周少吐槽；「长辈看着呢」感 | 镇守持续时间 +5%，或首次擦伤免一星 |
| `外国神物` | 第 2 问选「有」（十字架 / 御守一类） | 马科长偶尔愣一下；小路敬语多半句 | 假单/借面可疑点微加亮，或安神冷却微减 |
| `baifo.life观音` | 第 3 问（前两问都「没有」；可外链彩蛋） | 老周：「凑合一下」；点击可再开站点 | 无硬加成 / 或极微随机 |

第 21 关「你家」：点击护身物可释放一次「安心」护盾。关闭数值附录不影响通关。  
**劝善读法**：护身物是「我还是活人」的锚——序章老周已点明；不是伤害数值，是守夜的人需要的气味。
