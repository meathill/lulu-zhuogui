## 第 1 关｜让人发冷的电梯

### 标题 / 订单与单主口述

**订单文案**
> 【体验单·新手】城西锦华苑｜电梯轿厢监控  
> 症状：电梯特别冷，夏天还好，春秋难过；业主不敢久坐  
> 报酬：50 元｜预计 4–5 分钟

**单主口述（定稿）**
> 「我们小区的电梯不知道为啥，特别冷，夏天还好说，春秋天就难过了。空调？肯定没开啊，装都没装……」  
> 「我听街道孙主任说这片地方不好，以前城市小，这块是乱坟岗，后来直接清理一下就盖成小区了，不太干净……」  
> 「内什么，孙主任说找你们能行，你给看看？」

（App 备注栏可缩成物业小哥转述；完整口述进侦察语音 / 热点。）

### 塔防设定

- **路径为何走这里**：鬼渣（祟）喜欢聚集在电梯里**看广告**；从**门下缝**、门缝左右、电缆井、楼层指示缝往里聚。乱坟岗改小区，地底碎执念多，电梯这种「人来人往又密闭」的盒子最对它们胃口。  
- **敌人目标**：在轿厢里堆浓度、贴广告屏幕发呆；人一进门就发冷。  
- **玩家目标**：在**机位画面内**的缝隙贴符，让鬼渣**持续掉血直至消散**；学会看**符力条持续自回**、补贴（含被踢后）；掉落碎片为应急糖。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **单机位**（第 1–4 规则） |
| **位置 / 角度** | 轿厢天花板**某角** → **俯视约 45°**（物业常见安装） |
| **覆盖** | 感应门全幅（含**门下缝**与左右门缝）、轿厢地板、广告屏、按键区、楼层数码管/显示板、侧壁电缆井盖板（若在角机景深内） |
| **照不到** | **轿厢顶检修缝**、轿厢外井道——本关**不开放**贴符（合适但镜头外；标「需多机位、第 5 关后才可用」，本关路径上仍可有细祟从上「滴感」表现，但玩家无法在顶缝布塔） |

### 地图与路线

- 监控主视角：上述单机位轿厢内画面。  
- 电梯运行逻辑：到 **1、B1** 接人 → 再到 **7 / 8 / 9** 停让人下；偶发停层（含 **-3**）。  
- 路线示意：门下缝 / 门缝 / 侧壁缝 → 轿厢中央广告区（聚集点）。人进出时门开，吞吐加快；**脚会扫过门下缝的符**。

### 可贴符位点（塔位）

| 位点 | 说明 | 机位内 |
|---|---|---|
| **门下面的缝** | **本关主推教学位**：贴地，镜头正对；乘客进出可能**踢掉**→塔位空出，须补贴（并再耗符力） | ✓ |
| 门缝左右 | 开门时优先灌入的路；教学可强制贴一处（腰线以下入画） | ✓ |
| 楼层显示板缝 | 停层时短暂加压；在角机画面上沿 | ✓ |
| 电缆井盖板缝 | 侧向渗入；仅当盖板落在 45° 画面内时开放（默认开放） | ✓ |
| 广告屏下沿 / 边框 | 聚集点旁，伤得慢但罩面大；可选第三/四位点 | ✓ |
| 轿厢顶检修缝 | 俯视照不到 | ✗ 本关删除；**需多机位、第 5 关后才可用** |

第 1 关开放 **3–4 个画面内缝隙位点**（默认：门下缝 + 门缝左右其一 + 楼层板 + 电缆井或广告下沿）。符为「缝隙镇守教学版」（贴上即对经过路径持续掉血，**持续耗符力**）。侦察阶段强制点一次**门下缝** `?`（兼教踢符风险）。

### 波次（含一大波）

| 波 | 内容 |
|---|---|
| 侦察 | 逛热点；看浓度条；教**符力条持续自回**（主）；人未进时浓度缓慢涨 |
| 小波 1 | 1F 开门接人：门下缝细祟入；教贴第一张符（耗符力）；乘客经过时**演示踢符一次**并提示补贴 |
| 小波 2 | 上行 7F：电缆井 + 门缝；祟消散掉**符力碎片**（高亮，应急）；练习补第二位点 |
| **一大波** | 异常停 **-3**：多缝同时开，浓度骤升；教「先补门下缝/门缝再清聚集点」；碎片掉落偏多 |
| 收束 | 驶向 8/9：余祟消散掉碎片；厚重鬼渣入场（Boss） |

### Boss

**一块大块、厚重一点的鬼渣**：移动慢，血厚，爱贴在广告屏前。缝隙符持续削；可用教学版「点对准」轻击补刀（非点消为主）。击散后浓度回落。

### 失败条件

电梯里鬼聚多了人就冷；**累计超过 3 个乘客觉得冷** → 任务失败。  
（UI：乘客头像闪雪花；第三人冷时老周劝退。）

### 新机制（一关一件）

**在机位画面内的缝隙贴符（塔位）** + **符力持续自回**（贴符/维持耗能；祟散碎片为辅）+ 浓度条 + 扛一小波 / 一小大波；顺带体验**门下缝被踢**。问号热点教一次侦察习惯。

### 关键对话 / 劝诫钩

> 老周：进门先别急着砸。门下面那条缝、门两边——镜头里闪的地方，符贴上去，它们自己掉。  
> 老周：人一进一出，符可能被踢飞。不是坏了，是你贴在脚边上了。——盯着，补贴，符力别见底。  
> 老周：电梯里人少、又关得死，鬼渣爱往里钻看广告。缝里贴符，别让它们聚满。符力条自己会回；散了的碎片捡着应急，别把条抽干。  
> 孙主任（转述热点）：这块以前是乱坟岗……清理一下就盖了楼。  
> 小路：本单完成！实习进度 1/6～要加油接单才能吃饭哦！

劝诫落点：人少处别夜游逞能（半句，可跳过）。

### 掉落 / 桌面

- 掉落：D07 电梯广告贴纸角（可选）。  
- 桌面：便签「锦华苑电梯·门下缝·会被踢」；金币 +50。商店「符力补充」预告可点灰显。

## 第 2 关｜热水器在哭

**订单**
> 【驱祟单·新手】槐安里 12 栋 402｜合租房

**单主备注（大刘）**

> 大刘：完事了？室友说不烧了，但他刚输了一把又说想死。你们管吗？  
> 你：……这个不归我们管。

## 第 3 关｜路口便利店的香炉

### 标题 / 订单与单主口述

**订单**
> 【驱祟单·加急】城南路口｜24 小时便利店门口｜**交通摄像头**  
> 症状：门口不知谁搁了个香炉；有个醉汉眼睛发白，往炉上摆面包、点烟  
> 报酬：180 元｜本关只开路口这一路（交通摄像头教学）

**单主备注（小敏，店员语音即可，少出镜）**
> 香炉不是我们店的。那大叔眼神不对，嘴里念的也不是人话。我一个月三千五，不包括驱邪。——你们看路口监控就行，别让他在我门口拜完。

### 塔防设定

- **路径逻辑**：**吸引·路口香炉空祭**——便利店在**路口**；香炉在店门口，面包作供、烟当香，招孤魂与附身祟。附身驱使醉汉/大叔往炉上续摆、续点。涌出：路口人行线边、店门缝、炉周地面——都落在交通摄像头画面里。  
- **敌人目标**：催宿主把供摆满（喂香炉）；游离祟顺路口雾气扑炉与店门。  
- **玩家目标**：用**显形咒（净眼类）**让附身鬼**现形**，现形后才能打；打断续供，别让面包和烟凑满三份。  
- **少人**：少画全身路人；画面主看香炉、面包、烟、鬼影、路口斑马线与店招。醉汉用剪影/半身/远端晃影即可；店员以语音为主。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **单机位** |
| **位置 / 角度** | 路口杆上 / 灯臂上的**交通摄像头** → **俯视路口**约 45° |
| **覆盖** | 路口一角车道与斑马线、便利店门口、**香炉**（供品面包与烟入画）、店门缝附近；鬼影沿人行线与炉周游 |
| **照不到** | 店内货架深处、后仓——本关不切店内第二路；涌出与供奉都须在路口画面里完成 |

### 地图与路线

路口斑马线侧 → 店门口香炉（吸引锚）→ 门缝细祟汇炉。  
开局香炉上**已经摆着一块面包**（吸引已亮）。醉汉在炉边晃，要续摆、要点烟。

### 可贴符位点

| 位点 | 说明 | 机位内 |
|---|---|---|
| 香炉旁地面圈 | 减速偷吃与续供；挡孤魂凑炉 | ✓ |
| 店门缝外沿 | 挡门缝涌潮 | ✓ |
| 斑马线近端人行侧 | 涌出路减速 | ✓ |
| 灯杆/护栏入画处 | 可选镇守 | ✓（须入画） |
| 店内收银台 | 交通摄像头照不到 | ✗ 本关删 |

### 波次

| 波 | 内容 |
|---|---|
| 开局 | 香炉上已有**1 块面包**；教读失败进度（面包 / 烟） |
| 1 | 游离祟扑炉；教**显形咒**——附身没现形时打宿主无效或反噬提示 |
| 2 | 醉汉被驱使去续摆 / 点烟；显形后才能打附身核 |
| **一大波** | 第三次冲炉 / 要点第三只烟：附身核躁动 + 路口涌潮 |
| 收束 | 附身打掉；香炉供未满；余祟散或击退 |

### Boss

无独立 Boss；一大波时附身核脱出 / 躁动为高威胁（须已显形）。

### 失败条件（三阶）

开局：**1 块面包**已在炉上。  
失手一次 → 再摆面包并点烟（进度往上爬）。  
凑满**三块面包并点上三只烟** → **彻底失败**（共 **3 次**失手机会）。  
另：未显形就乱打、把宿主打重伤 → 也可直接失败。

人话进度：炉上多一块面包、多一只烟，你就知道自己又慢了半步。

### 新机制（一关一件）

**显形咒（净眼类）**：附身鬼必须先现形，才能攻击。宿主不可当杂兵砸。本关主课是显形 + 打断空祭进度。

### 关键对话 / 劝诫钩

> 老周：先显形。附身没现出来你打谁？  
> 老周：香炉上那块面包不是他买着玩的。——别让他摆满三块、点满三只烟。  
> 醉汉（驱邪后，恍惚）：……我买面包干嘛？门口那炉子谁搁的？  
> 小敏（电话）：大哥你账结了就走，别在我门口拜。——香炉谁扔的我不知道，少一个是一个。  
> 小路：（结算）宿主保护分还行哦～下次加购「金牌驱散」更干净呢！  
> 结算可闪：路边香炉别瞎拜；空祭喂的是鬼不是佛。

### 掉落 / 桌面

半袋切片面包包装 / 烟蒂风味位（可选）。侦察笔记：「路口香炉·面包·烟」。

## 第 4 关｜末班 404

### 标题 / 订单与单主口述

**订单**
> 【驱祟单】夜班 404 路｜车载监控  
> 症状：末班车位子总是满的；靠窗女孩说隔壁座发冷；到站又有人凭空少一截  
> 报酬：160 元

**单主备注（老郑，司机）**
> 车上不只有活人。好多是善鬼，正常坐车回家。——别整太吓人，我有高血压。女孩坐靠窗那排，你盯着点。

### 塔防设定

- **路径**：深夜车厢里，许多乘客是**善鬼**——只是赶路，不害人。它们忌驱离符，会被赶到**后半节车厢**；到站就自然下车。邪祟仍会沿过道扑**靠窗活人座**。  
- **敌人目标**：邪祟贴女孩抢阳气；善鬼若挤回前排会挡视线、搅操作（非主威胁）。  
- **玩家目标**：用**驱离符**把善鬼往后天；给女孩**旁边的座椅**贴驱离符，护住她。狗牌预埋仍可在靠窗一带闪过。  
- **少人**：单路车厢；少画乘客正脸全身；善鬼用简轮廓 / 半透明剪影。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **单机位**（车载；本关不切第二路） |
| **位置 / 角度** | 车厢**中段顶置** → 俯视约 **45°**，能分清前 / 中 / 后三节 |
| **覆盖** | 过道、靠窗女孩座与**旁座**、前后门附近、后半节善鬼堆积区 |
| **照不到** | 驾驶台内侧仪表——不开放；站台延伸光为演出，不布塔 |

### 地图与路线

前门 / 中门 → 过道 → 靠窗中排（女孩 + 旁座驱离符位）→ 后半节（善鬼被驱离符赶到这儿，到站下车）。
