## 第 1 关｜让人发冷的电梯

### 标题 / 订单与单主口述

**订单文案**
> 【体验单·新手】城西锦华苑｜电梯轿厢监控  
> 症状：电梯特别冷，夏天还好，春秋难过；业主不敢久坐  
> 报酬：50 元｜预计 4–5 分钟

**单主口述（定稿）**
> 「我们小区的电梯不知道为啥，特别冷，夏天还好说，春秋天就难过了。空调？肯定没开啊，装都没装……」  
> 「我听街道孙主任说这片地方不好，以前城市小，这块是乱坟岗，后来直接清理一下就盖成小区了，不太干净……」  
> 「内什么，孙主任说找你们能行，你给看看？」

（App 备注栏可缩成物业小哥转述；完整口述进侦察语音 / 热点。）

### 塔防设定

- **路径为何走这里**：鬼渣（祟）喜欢聚集在电梯里**看广告**；从**门下缝**、门缝左右、电缆井、楼层指示缝往里聚。乱坟岗改小区，地底碎执念多，电梯这种「人来人往又密闭」的盒子最对它们胃口。  
- **敌人目标**：在轿厢里堆浓度、贴广告屏幕发呆；人一进门就发冷。  
- **玩家目标**：在**机位画面内**的缝隙贴符，让鬼渣**持续掉血直至消散**；学会看**符力条持续自回**、补贴（含被踢后）；掉落碎片为应急糖。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **单机位**（第 1–4 规则） |
| **位置 / 角度** | 轿厢天花板**某角** → **俯视约 45°**（物业常见安装） |
| **覆盖** | 感应门全幅（含**门下缝**与左右门缝）、轿厢地板、广告屏、按键区、楼层数码管/显示板、侧壁电缆井盖板（若在角机景深内） |
| **照不到** | **轿厢顶检修缝**、轿厢外井道——本关**不开放**贴符（合适但镜头外；标「需多机位、第 5 关后才可用」，本关路径上仍可有细祟从上「滴感」表现，但玩家无法在顶缝布塔） |

### 地图与路线

- 监控主视角：上述单机位轿厢内画面。  
- 电梯运行逻辑：到 **1、B1** 接人 → 再到 **7 / 8 / 9** 停让人下；偶发停层（含 **-3**）。  
- 路线示意：门下缝 / 门缝 / 侧壁缝 → 轿厢中央广告区（聚集点）。人进出时门开，吞吐加快；**脚会扫过门下缝的符**。

### 可贴符位点（塔位）

| 位点 | 说明 | 机位内 |
|---|---|---|
| **门下面的缝** | **本关主推教学位**：贴地，镜头正对；乘客进出可能**踢掉**→塔位空出，须补贴（并再耗符力） | ✓ |
| 门缝左右 | 开门时优先灌入的路；教学可强制贴一处（腰线以下入画） | ✓ |
| 楼层显示板缝 | 停层时短暂加压；在角机画面上沿 | ✓ |
| 电缆井盖板缝 | 侧向渗入；仅当盖板落在 45° 画面内时开放（默认开放） | ✓ |
| 广告屏下沿 / 边框 | 聚集点旁，伤得慢但罩面大；可选第三/四位点 | ✓ |
| 轿厢顶检修缝 | 俯视照不到 | ✗ 本关删除；**需多机位、第 5 关后才可用** |

第 1 关开放 **3–4 个画面内缝隙位点**（默认：门下缝 + 门缝左右其一 + 楼层板 + 电缆井或广告下沿）。符为「缝隙镇守教学版」（贴上即对经过路径持续掉血，**持续耗符力**）。侦察阶段强制点一次**门下缝** `?`（兼教踢符风险）。

### 波次（含一大波）

| 波 | 内容 |
|---|---|
| 侦察 | 逛热点；看浓度条；教**符力条持续自回**（主）；人未进时浓度缓慢涨 |
| 小波 1 | 1F 开门接人：门下缝细祟入；教贴第一张符（耗符力）；乘客经过时**演示踢符一次**并提示补贴 |
| 小波 2 | 上行 7F：电缆井 + 门缝；祟消散掉**符力碎片**（高亮，应急）；练习补第二位点 |
| **一大波** | 异常停 **-3**：多缝同时开，浓度骤升；教「先补门下缝/门缝再清聚集点」；碎片掉落偏多 |
| 收束 | 驶向 8/9：余祟消散掉碎片；厚重鬼渣入场（Boss） |

### Boss

**一块大块、厚重一点的鬼渣**：移动慢，血厚，爱贴在广告屏前。缝隙符持续削；可用教学版「点对准」轻击补刀（非点消为主）。击散后浓度回落。

### 失败条件

电梯里鬼聚多了人就冷；**累计超过 3 个乘客觉得冷** → 任务失败。  
（UI：乘客头像闪雪花；第三人冷时老周劝退。）

### 新机制（一关一件）

**在机位画面内的缝隙贴符（塔位）** + **符力持续自回**（贴符/维持耗能；祟散碎片为辅）+ 浓度条 + 扛一小波 / 一小大波；顺带体验**门下缝被踢**。问号热点教一次侦察习惯。

### 关键对话 / 劝诫钩

> 老周：进门先别急着砸。门下面那条缝、门两边——镜头里闪的地方，符贴上去，它们自己掉。  
> 老周：人一进一出，符可能被踢飞。不是坏了，是你贴在脚边上了。——盯着，补贴，符力别见底。  
> 老周：电梯里人少、又关得死，鬼渣爱往里钻看广告。缝里贴符，别让它们聚满。符力条自己会回；散了的碎片捡着应急，别把条抽干。  
> 孙主任（转述热点）：这块以前是乱坟岗……清理一下就盖了楼。  
> 小路：本单完成！实习进度 1/6～要加油接单才能吃饭哦！

劝诫落点：人少处别夜游逞能（半句，可跳过）。

### 掉落 / 桌面

- 掉落：D07 电梯广告贴纸角（可选）。  
- 桌面：便签「锦华苑电梯·门下缝·会被踢」；金币 +50。商店「符力补充」预告可点灰显。

## 第 3 关｜便利店门外的香炉

### 标题 / 订单与单主口述

**订单**
> 【驱祟单·加急】城南 24 小时便利店｜门口 / 收银监控  
> 症状：门口不知谁扔了个香炉；有个大叔眼睛发白，进店买面包，出来就要往香炉上摆  
> 报酬：180 元｜监控（本关**单路教学**；店内物理多路第 5 关后解锁切换）

**单主备注（小敏）**
> 门口那个香炉不是我们店的。大叔进来买面包，眼神不对，嘴里念的也不是人话。我一个月三千五，不包括驱邪。

### 塔防设定

- **路径逻辑**：门外**香炉贡品**吸引孤魂与附身祟（**吸引·店铺外香火 / 空祭**）→ 附身驱使大叔进店**买面包**再回来供，完成空祭、喂大吸引点。涌出处符合便利店环境：**门缝、巷角、货架脚缝**等，均须落在**单机位画面内**。  
- **敌人目标**：催大叔完成祭拜（喂香炉）；游离祟顺路扑店员小敏（阳气）。  
- **玩家目标**：**净眼**看清附身 → 帮他驱邪 → **护送他离开摄像头覆盖区**（出镜 = 本关安全终点）。画面应能一眼认：香炉是钩、大叔是被驱使的宿主、覆盖区外沿是出口。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **单机位**（物理上可有多路，本关**不切换**） |
| **位置 / 角度** | **收银台上方**俯视约 **45°**，朝向店门与门外近端人行道 |
| **覆盖** | 收银台侧、冰柜侧面、门口内侧、门外**香炉**与人行道近端经玻璃门入画；**覆盖区外沿**（画面边缘外）= 护送终点 |
| **照不到** | 货架最深死角、后仓、巷道远端——本关不开放塔位；涌出表现须改到入画的门缝 / 巷角入口 |

### 地图与路线

店内货架环线 → 收银台（小敏）→ 门 → **门外香炉**（吸引锚）→ 人行道近端 → **镜头外沿（护送终点）**。  
支路：巷角 / 门缝细祟往香炉与大叔汇。香炉、门缝涌出、外沿终点均须在收银机位透过玻璃可见或可判断。

### 可贴符位点

| 位点 | 说明 | 机位内 |
|---|---|---|
| 门口内侧 | 镇守减速出门潮；护护送走廊 | ✓ |
| 香炉旁地面圈 | 减速 / 挡孤魂偷吃与祭拜完成；勿让大叔轻易摆下 | ✓（经玻璃入画） |
| 冰柜侧面 | 挡货架环线扑店员 | ✓ |
| 收银台侧 | 护小敏近塔 | ✓ |
| 巷角入画口 | 涌出处减速 | ✓（须入画） |
| 后仓门缝 | 镜头外 | ✗ 本关删 |

### 波次

| 波 | 内容 |
|---|---|
| 1 | 游离祟扑小敏；教**净眼前勿乱打宿主**（大叔仍在店内晃） |
| 2 | 大叔被驱使去拿面包 / 结账；香炉侧孤魂偷吃加压 |
| **一大波** | **大叔出店门冲向香炉**：附身核躁动 + 巷角 / 门缝涌潮 |
| 收束 | 净眼逼出 / 打落附身 → **护送大叔走出摄像头覆盖区**；余祟回香炉可清或击退 |

### Boss

无独立 Boss；一大波时附身核脱出 / 躁动为高威胁单位（仍不可直接当宿主砸）。

### 失败条件

**大叔买下面包并摆下祭拜**（完成空祭、喂吸引点）→ 失败；或店员被冲倒 / 宿主被误伤重伤。

### 新机制

**净眼符**认附身；宿主不可直接乱打；**护送出镜**（离开本关摄像头覆盖区 = 安全）。糯米等挡路道具可作可选辅助，本关主课是净眼 + 护送。

### 关键对话 / 劝诫钩

> 老周：净眼先看清是谁在说话。那香炉不是店里的——别让他拜完。  
> 老周：护他走出镜头。出了这圈，他才算安全；留在香炉边上，附身还能再把他拽回去。  
> 大叔（驱邪后，恍惚）：……我买面包干嘛？门口那炉子谁搁的？  
> 小敏：大哥你账结了就往外走，别在我门口拜。——香炉谁扔的我不知道，少一个是一个。  
> 小路：（结算甜声）宿主保护分不错哦～下次记得加购「金牌驱散」更干净呢！  
> 结算可闪：路边香炉别瞎拜；空祭喂的是鬼不是佛。

### 掉落 / 桌面

D06 可改为「半袋切片面包包装」或保留关东煮竹签风味位。侦察笔记：「门外香炉·空祭」。
