## 第 1 关｜让人发冷的电梯

### 标题 / 订单与单主口述

**订单文案**
> 【体验单·新手】城西锦华苑｜电梯轿厢监控  
> 症状：电梯特别冷，夏天还好，春秋难过；业主不敢久坐  
> 报酬：50 元｜预计 4–5 分钟

**单主口述（定稿）**
> 「我们小区的电梯不知道为啥，特别冷，夏天还好说，春秋天就难过了。空调？肯定没开啊，装都没装……」  
> 「我听街道孙主任说这片地方不好，以前城市小，这块是乱坟岗，后来直接清理一下就盖成小区了，不太干净……」  
> 「内什么，孙主任说找你们能行，你给看看？」

（App 备注栏可缩成物业小哥转述；完整口述进侦察语音 / 热点。）

### 塔防设定

- **路径为何走这里**：鬼渣（祟）喜欢聚集在电梯里**看广告**；从门缝、电缆井、楼层指示缝、轿厢顶检修缝往里聚。乱坟岗改小区，地底碎执念多，电梯这种「人来人往又密闭」的盒子最对它们胃口。  
- **敌人目标**：在轿厢里堆浓度、贴广告屏幕发呆；人一进门就发冷。  
- **玩家目标**：在缝隙贴符，让鬼渣**持续掉血直至消散**，不让聚集浓度过大。

### 地图与路线

- 监控主视角：**轿厢内**（广告屏、按键、楼层数码管、感应门）。  
- 电梯运行逻辑：到 **1、B1** 接人 → 再到 **7 / 8 / 9** 停让人下；偶发停层（含 **-3**）。  
- 路线示意：各方向缝隙 → 轿厢中央广告区（聚集点）。人进出时门开，缝隙吞吐加快。

### 可贴符位点（塔位）

| 位点 | 说明 |
|---|---|
| 门缝左右 | 开门时优先灌入的路；教学强制贴一处 |
| 轿厢顶检修缝 | 从上往下滴的细祟 |
| 电缆井盖板缝 | 侧向渗入 |
| 楼层显示板缝 | 停层时短暂加压 |
| 广告屏边框（可选后期） | 聚集点旁，伤得慢但罩面大 |

第 1 关开放 **3–4 个缝隙位点**；符为「缝隙镇守教学版」（贴上即对经过路径持续掉血）。侦察阶段强制点一次门缝 `?`。

### 波次（含一大波）

| 波 | 内容 |
|---|---|
| 侦察 | 逛热点；看浓度条教学；人未进时浓度缓慢涨 |
| 小波 1 | 1F 开门接人：门缝细祟入；教贴第一张符 |
| 小波 2 | 上行 7F：电缆井 + 顶缝；练习补第二位点 |
| **一大波** | 异常停 **-3**：多缝同时开，浓度骤升；教「先补门缝再清聚集点」 |
| 收束 | 驶向 8/9：余祟消散；厚重鬼渣入场（Boss） |

### Boss

**一块大块、厚重一点的鬼渣**：移动慢，血厚，爱贴在广告屏前。缝隙符持续削；可用教学版「点对准」轻击补刀（非点消为主）。击散后浓度回落。

### 失败条件

电梯里鬼聚多了人就冷；**累计超过 3 个乘客觉得冷** → 任务失败。  
（UI：乘客头像闪雪花；第三人冷时老周劝退。）

### 新机制（一关一件）

**在缝隙贴符（塔位）** + 看轿厢**浓度条** + 扛一小波 / 一小大波。问号热点顺带教一次（为侦察习惯，非本关主课）。

### 关键对话 / 劝诫钩

> 老周：进门先别急着砸。门缝、顶缝，闪的地方——符贴上去，它们自己掉。  
> 老周：鬼渣爱在电梯里看广告。人少、阳气断得干净的盒子，最对胃口。——缝里贴符，别让它们聚满。  
> 孙主任（转述热点）：这块以前是乱坟岗……清理一下就盖了楼。  
> 小路：本单完成！实习进度 1/6～要加油接单才能吃饭哦！

劝诫落点：人少处别夜游逞能（半句，可跳过）。

### 掉落 / 桌面

- 掉落：D07 电梯广告贴纸角（可选）。  
- 桌面：便签「锦华苑电梯·缝要贴」；金币 +50。商店入口灰显预告。

## 第 2 关｜热水器在哭

### 标题 / 订单与单主口述

**订单**
> 【驱祟单·新手】槐安里 12 栋 402｜合租房  
> 症状：夜里卫生间有哭声，热水器自己打火，室友连续发烧三天  
> 报酬：80 元

**单主备注（大刘）**
> 房东说这楼下个月拆，先别报修。室友烧到三十九度了还在打游戏，顺便看看是不是中邪。

### 塔防设定

- **路径**：祟从**地漏 / 瓷砖缝 / 卫生间门缝**涌出，沿走廊扑向发烧室友房门（阳气热源最香）。  
- **敌人目标**：吸室友余热，堆走廊浓度。  
- **玩家目标**：镇宅挡住走廊主路，五雷清高威胁团，护住室友烧退。

### 地图与路线

卫生间（地漏源）→ 狭廊 → 室友房门。支路：窗外拆迁公告墙渗入的细丝（风味）。

### 可贴符位点

| 位点 | 说明 |
|---|---|
| 走廊中段地面 | **镇宅**主塔，挡主路 |
| 卫生间门框 | 减地漏吞吐 |
| 室友门缝外侧 | 近身护阳气 |
| 地漏旁（可选） | 源点减速 |

### 波次

| 波 | 内容 |
|---|---|
| 1 | 地漏细祟，教贴镇宅 |
| 2 | 门缝 + 瓷砖缝双路，教五雷补刀 |
| **一大波** | 热水器打火 +「哭声」峰：地漏双路涌出 |
| 收束 | 余祟回地漏；铜铃远音 |

### Boss

无独立 Boss；一大波头目为「哭声团」（稍厚祟核）。

### 失败条件

室友**高烧倒下**（阳气条空），或走廊**浓度破线**（整屋发冷失败）。

### 新机制

**镇宅符**（镇守）+ **五雷符**（攻击，4 点无禁点）。

### 关键对话 / 劝诫钩

> 老周：看清亮的顺序，一笔下去。符在屏幕上，不在纸上。  
> 老周：合租也别半夜瞎转卫生间。发烧了先睡觉。  
> 大刘：完事了？室友说不烧了，但他刚输了一把又说想死。你们管吗？  
> 你：……这个不归我们管。

### 掉落 / 桌面

D08 铜铃碎片（弱）。新手贴纸、提神糖。商店「高清镜头」预告。

## 第 3 关｜便利店的醉汉

### 标题 / 订单与单主口述

**订单**
> 【驱祟单·加急】城南 24 小时便利店  
> 症状：男子徘徊一小时，眼睛发白，嘴里念的不是人话  
> 报酬：180 元｜监控 4 路

**单主备注（小敏）**
> 他一直盯着关东煮。我一个月三千五，不包括这个。

### 塔防设定

- **路径**：附身祟被**井口**吸引，醉汉身体冲向门外井盖；游离祟绕货架扑店员（阳气）。  
- **敌人目标**：回井；顺手撞倒店员。  
- **玩家目标**：净眼看清 → 逼出附身 → 糯米挡井盖路；护店员。

### 地图与路线

店内货架环线 → 收银台（小敏）→ 门 → 井盖。井盖有「吸力」改道箭头。

### 可贴符位点

| 位点 | 说明 |
|---|---|
| 门口内侧 | 镇守减速出门潮 |
| 井盖周围糯米位 | **糯米**挡路（消耗塔） |
| 冰柜侧面 | 挡货架环线 |
| 收银台侧 | 护店员近塔 |

### 波次

| 波 | 内容 |
|---|---|
| 1 | 游离祟扑小敏，教净眼前勿乱打宿主 |
| 2 | 醉汉开始挪向门 |
| **一大波** | 附身脱出瞬间 + 井盖回灌一小潮 |
| 收束 | 追击驱散或击退放走 |

### Boss

无；附身核脱出时为高威胁单位。

### 失败条件

店员被冲倒，或宿主被误伤重伤，或井口浓度破线（店门冰雾锁死）。

### 新机制

**净眼符**；附身不可直接打宿主；**糯米**挡路；击退 vs 驱散后果初感。

### 关键对话 / 劝诫钩

> 醉汉（清醒）：我不就下午多看了一眼那口井吗……  
> 小敏：大哥，你欠我一根烤肠钱。  
> 结算可闪：井口别凑热闹。

### 掉落 / 桌面

D06 关东煮竹签。糯米袋入道具库。

### 地图与路线

后门 → 过道 → 中排（女生+狗牌预埋）→ 前排阿婆 → 司机位。虚站开门时路径延伸到站台光。

### 波次

| 波 | 内容 |
|---|---|
| 1 | 过道细祟找座 |
| 2 | 阿婆起身走向虚站，祟试图冲散 |

| 处理 | 四种处理 UI |

### Boss

无；阿婆为有名鬼（非血条 Boss）。

### 失败条件

### 新机制

**八卦符**、**引魂灯**；**四种处理完整 UI** 首次。

### 关键对话 / 劝诫钩

> 周阿婆：槐安里还没到吗？我孙女在站台等我，她才六岁。  
> 老周：选之前想三秒。  
> 你（独白）：布丁……？先记下。

### 掉落 / 桌面

## 第 6 关｜安神与铜铃

### 标题 / 订单与单主口述

**订单**
> 【驱祟单】滨河出租屋｜手机 + 床头支架  
> 症状：同一条巷子的噩梦，耳边铃声，白天恍惚  
> 报酬：150 元

**单主备注（小唐）**
> 梦里总有小孩哭，还有铜铃。巷子墙上全是拆迁公告。

### 塔防设定

- **路径**：梦浅层里，**红皮鞋**踩着拆迁公告墙前进，巷子接到床头；祟沿鞋印渗入现实卧室门缝。  
- **敌人目标**：踩破安神，把人拖进深巷。  
- **玩家目标**：安神守夜；铜铃打断蓄力；清渗入祟。

### 地图与路线

现实：门缝 / 窗 → 床头。梦层叠化：巷墙 → 床沿（红皮鞋路径）。

### 可贴符位点

| 位点 | 说明 |
|---|---|
| 床头安神位 | **安神符**主塔，撑安神条 |
| 门框镇宅 | 挡现实渗入 |
| 窗台 | 支路 |
| 铜铃图标（主动） | 打断梦扰蓄力（有限次） |

### 波次

| 波 | 内容 |
|---|---|
| 1 | 门缝细祟，安神条教学 |
| 2 | 梦层浅显，鞋印出现 |
| **一大波** | 红皮鞋踩到床沿：梦扰蓄力峰（铜铃教打断） |
| 收束 | 清余祟；群聊芮姐 |

### Boss

无；梦扰核为蓄力单位。

### 失败条件

**安神条破**（小唐强行惊醒且恍惚判定失败）。

### 新机制

**安神符**、**铜铃**；天赋树开放。

### 关键对话 / 劝诫钩

> 老周：梦里也别往拆迁巷子钻。——白天醒着，晚上安神。  
> 苏芮：（群聊）新人？夜班调度要是让你碰槐安里的井，先问我……  
> 小路：恭喜转为见习驱祟师！

### 掉落 / 桌面
