## 11.0 背景设定（前置因果）

1. **老槐树与神龛来历**：1994年夏天，六岁女童小梅在老槐树下失踪，锁怨井恶煞「荒」渗出。当年年轻的老周被恶煞欺骗吸走双眼视力，后与道家师父舍命立下槐神龛与七镇封印。
2. **拆迁危局**：三十年后，槐安里拆迁工程推进到核心区，推土机开进院落，地脉震动导致三十年封印松动。
3. **老孙的难处**：老实巴交的街道治安巡逻员老孙，受辖区派出所委托盯守拆迁警戒线。夜里听到小庙前的小孩哭声，心里发毛又心疼，用手机连麦民俗中心求助。
4. **囡囡的恶毒诱骗**：恶煞借小梅童稚的脸孔化身「囡囡」，专挑活人的软肋下手，一步步诱骗巡查员撕下神龛旧符、推倒香炉，甚至在契约符上写下名字，以此夺取巡查网络权限。

## 第 11 关｜槐安里的哭声 （反套路·起）

### 标题 / 订单与单主口述

**订单**
> 【临江民俗中心·现场协查】槐安里 3 号院（待拆）｜看守手机 + 临时监控 2 路  
> 症状：夜里院子里有小孩哭声，拆迁工人与巡逻队员不敢进场  
> 报酬：260 元

**单主备注（老孙，治安巡逻员）**
> 「周师傅，派出所让我在这儿盯拆迁警戒线。这……这娃娃坐在小庙台阶上哭半宿了。我给她扔大白兔奶糖，糖穿过她身子掉泥里了……我夜巡十来年没见过这阵仗，地上连个影子都没有，你们快给瞅瞅！」

### 塔防设定

- **路径逻辑**：**哭声**像饵，把院外细祟从推土机轮廓、院墙缝、排水口引来；每答应囡囡一个请求，封印松一层，**可走路径变多**。  
- **吸引点**：**废弃神龛**——香火将断，鬼仍偷偷来吃残祭；龛周细祟比墙缝更黏，像围着盘子。  
- **敌人目标**：灌满院坝，蹭松槐神龛封印；顺嘴偷残祭。  
- **玩家目标**：对话应对三请求（记录受骗 0–3）；后半清哭声引潮，尽量护住封印层。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **多机位（2 路固定 + 临时）**——龛向枪 + 院墙/坝心枪；**看守（老孙）手机**作补盲临时路 |
| **覆盖** | 龛门前、香炉周、院墙可见缝、排水口（须入坝心或墙向画面）；推土机阴影为路径源，塔位贴在阴影与院坝交界入画处 |
| **不稳手机位（点名例）** | 老孙**接电话 / 熄屏 / 揣兜** → 手机路**随时掉线**；来电 UI 半拍预警；掉线后该路塔冻结至重连。**关键护龛塔仍贴在龛向固定枪** |
| **注意** | 「院墙四缝」若某缝在枪后，则该缝只出祟不布塔，或切辅路才开放 |

### 地图与路线

院坝中央（囡囡对话区）← 院墙四缝 / 排水口 / 推土机阴影。龛周阴路：封印完好时切断，松则贯通；残祭吸引细祟围龛。

### 可贴符位点

| 位点 | 说明 | 所属机位 |
|---|---|---|
| 院墙可见缝外侧 | 镇守削引潮 | 院墙/坝心 |
| 龛门前地面 | 护旧封符，减少「误撕」压力外溢 | 龛向 |
| 排水口 | 源点减速 | 坝心（须入画） |
| 香炉周（若未推） | 香火减速环 | 龛向 |

### 波次

| 波 | 内容 |
|---|---|
| 对话段 | 三请求；几乎不教新符 |
| 轻潮 1 | 受骗=0 时仅墙缝细祟 |
| **一大波** | 每答应一次请求后哭声变调：对应缝全开引潮（受骗越高越大） |
| 收束 | 清院；记录 `囡囡受骗` |

### Boss

无；囡囡为对话反派（净眼可骗）。

### 失败条件

封印层在引潮中**全破**且院坝浓度破线；或看守被冲散（单主弃单）。

### 新机制

纯抉择为主；旧封符表现；答应越多封印越松、祟潮越多（轻塔防后果）。

### 关键对话 / 劝诫钩

> 老孙：“周师傅，那女娃哭得我浑身发毛……我兜里还有半包饼干，想递过去又不敢。”  
> 囡囡（揉着眼睛，满脸泪水，软糯可怜）：“{称呼}……你是派出所的叔叔吗？囡囡好冷……妈妈去买糖，叫囡囡在庙门口别动。那门上的黄纸字好凶，囡囡看着心口疼，你帮囡囡撕了好不好？”  
> 老周（耳机里打火机声一顿，嗓音沉郁得发闷）：“老孙，把饼干揣回去。小周，手从鼠标上拿开，别碰屏幕上的旧符。三十年前……我就是信了这声哭，才把一双眼珠子扔在槐安里这口烂井里的。这是借面煞，三十年了，翻来覆去就这几句台词，专门吃生人的心软。”  
> 囡囡（见被戳破，哭声骤停，嘴角猛地撕裂到耳根，发出森冷的阴笑）：“周叔叔……三十年了，你那双烂在井里的招子，阴雨天还疼不疼呀？”  
> 老周（冷笑一声，吐出一口浓烟）：“疼啊，每到下雨天就提醒我多盯紧这口破井。小周，别跟它废话，布阵守住神龛，按规矩把院子里的碎祟全清了。”

三请求表：

| 请求 | 表面理由 | 实际后果 |
|---|---|---|
| ① 撕龛门旧符 | 「字好凶，一看就疼」 | 封印第一层破 |
| ② 推倒香炉 | 「香呛，妈妈说香灰会埋小孩」 | 槐神香火断（影响 19、23） |
| ③ 契约符写「囡囡」 | 「给我一个名字」 | 获玩家频道权限 |
