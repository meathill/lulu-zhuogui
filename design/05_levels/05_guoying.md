# 05 · 桂英线｜第 15–16 关

## 第 15 关｜自己关掉的煤气 （温情线三·起）

### 标题 / 订单与单主口述

**订单**
> 【驱祟单·远程看护】槐安里 18 栋 201｜家用摄像头 2 路  
> 症状：燃气灶旋钮半夜自转；老人常对空气说话  
> 报酬：240 元

**单主备注（程雯）**
> 我在外地。我爸一个人住，记性不好了。半夜灶台的火自己灭、被子自己盖。我妈走了三年了……

### 塔防设定

- **路径**：祟扑**灶台旋钮**（想拧到开）与程老师床位；桂英虚影在灶前挡，越挡越淡。窗外水泥封井方向有细丝回望。  
- **敌人目标**：煤气开而不关；冲倒老人；顺带打散桂英。  
- **玩家目标**：保护型塔防——同时护灶台「关」、程老师、桂英残存。

### 地图与路线

厨房灶台 ← 窗缝 / 地漏细路；卧室床 ← 门缝。两路摄像头可切换。

### 可贴符位点

| 位点 | 说明 |
|---|---|
| 灶台两侧 | 主保护塔，保「关」 |
| 床头安神进阶位 | 护程老师 |
| 窗缝（封井向） | 削回灌 |
| 桂英常站位旁 | 给虚影「站住」的锚（表现层） |

### 波次

| 波 | 内容 |
|---|---|
| 1 | 旋钮轻转，教看灶状态条 |
| 2 | 床位支路祟 |
| **一大波** | 旋钮连转：灶台双路夹击 |
| 处理 | 驱散 / 报阴 / 暂不处理告诉程雯真相 |

### Boss

无；桂英为有名鬼（保护对象兼单位）。

### 失败条件

煤气开而不关**超时**，或程老师被冲倒，或桂英被打散导致本支线失败结算（仍可进换关）。

### 新机制

保护型塔防；安神进阶可贴床头。

### 关键对话 / 劝诫钩

> 桂英：你是小雯请来的？……我该走。可他煤气开了就忘……我走了谁给他关火？  
> 你：（视频）程女士，您家的「鬼」，是您妈。  
> ——独居老人煤气要有人盯。

### 掉落 / 桌面

D11 煤气灶旋钮橡胶垫。旗标 `桂英`。

## 第 16 关｜再煮一碗面 （温情线三·结）

### 标题 / 订单与单主口述

**触发**：【桂英=待续】最佳。驱散/报阴则换「空房子」（仍可读笔记获主线线索；塔防改为清空屋回灌潮）。

**订单**
> 【续单】槐安里 18 栋 201  
> 备注：让我爸再见我妈一面。一眼就行。  
> 报酬：程雯出价 500（平台「暂无定价」）

### 塔防设定

- **路径**：开眼滤镜开启时阳阴交汇，祟从**厨房小窗 / 封井向 / 门缝**涌向父子（父女）相见点。  
- **敌人目标**：打断相见，灌满厨房。  
- **玩家目标**：3 分钟滤镜内完成相见；守住交汇引来的祟潮；其后留灯或往生。

### 地图与路线

厨房小窗主灌入口 → 灶台与餐桌相见圈；笔记桌为侦察热点（老周往事）。

### 可贴符位点

| 位点 | 说明 |
|---|---|
| 小窗内外 | 主拦潮 |
| 餐桌圈外侧 | 护相见 |
| 门缝 | 支路 |
| 开眼仪式阵眼（关前布） | 滤镜稳定 |

### 波次

| 波 | 内容 |
|---|---|
| 开眼前 | 布阵；读笔记线索 |
| 滤镜前段 | 轻潮，对话优先 |
| **一大波** | 开眼峰值约 90 秒：封井方向回灌 |
| 倒计时末 | 守住收束；处理留灯/往生 |

### Boss

无。

### 失败条件

倒计时内相见中断且人倒，或浓度破线强制关滤镜（相见失败）。

### 新机制

**开眼仪式符** + **摄像头滤镜「开眼」**；限时塔防。

### 关键对话 / 劝诫钩

> 程老师：……桂英？  
> 桂英：看什么看，面要糊了。……我理了，你听不见嘛。  
> 你（独白）：我这辈子没这么想让一个倒计时慢一点。  
> ——听完再送，别贪「干净」。

### 掉落 / 桌面

铜顶针；纸条「他扣子也老扣错」。旗标 `桂英=留灯/往生`。
