# 05 · 布丁弧｜第 7–10 关

> design-v4.1 ｜ **机位克制**（本弧默认**单机位**）；**符只对鬼祟**（无安神、不给人镇静）；**撕符**可回收位点；**定神→召唤阴差**（阴差只收完整/有名魂）。  
> 第7主课：驱离引角 + 定神 + 唤阴差 + 撕符分离；第8叙事挂饰（布丁不出现）；第9空车棚影子试探（换掉浅梦安神）；第10林小禾卧室=**首次Boss**（控场+输出打梦魇，无安神入梦）。挂**聚阴古树**吸引（第7）。  
> 失败通用：老周劝退 → 本关重开 / 读取进度。

## 第 7 关｜步道上的黄影子 （温情线一·起）

### 标题 / 订单与单主口述

**订单**
> 【驱祟单】锦华苑小区｜夜间步道 + 花坛一角  
> 症状：连续半个月夜巡看到「黄白色肥敦敦的狗影」在步道与花坛之间转；晚归业主说「路边黑影一排一排的」  
> 报酬：150 元｜小区监控（**单路**：步道/花坛角枪）

**单主备注（老韩）**
> 我五十八了。那玩意儿老在三号花坛到步道那一段转——**一看就是狗**，拉布拉多那种肥。别弄太大动静。另外——人一走，路边就像有东西在……舔地。

### 塔防设定

- **路径逻辑**：人散后，步道上浮着**阳气碎渣**；祟团沿步道—花坛来**啃食**。**布丁明显是狗**（肥敦敦黄白、狗形轮廓、偶尔无声张嘴）——不啃阳气，嗅「放学的味道」；祟冲向碎光时它可能扑挡，越扑越虚。  
- **吸引点**：**聚阴古树**——三号花坛侧老树根阴沉，细祟爱趴根吸。  
- **预先准备好的角落坑**：花坛死角 / 树根旁划出**交接角**（画面内一目了然）。  
- **敌人目标**：啃光碎渣；缠住布丁让它与祟团糊成一团。  
- **玩家目标（主课）**：  
  1. 用**驱离符**（PvZ 大蒜式，只改道不伤）把布丁**引到角落坑**；  
  2. **撕符**把布丁与周围祟团**分开**（回收位点、打断混叠效果）；  
  3. 角落内**定神**顶住足够长时间；  
  4. UI 亮起**召唤阴差**——点出带走（阴差**只收完整/有名魂**；点普通祟团无效或马科长拒收）。  
- **禁砸**：五雷等**攻击性符会伤到布丁**→不能当杂兵砸；须先驱离分开再定神。  
- **少人**：步道空镜——碎光、狗影、树根、路灯噪点；老韩只出语音 / 远端剪影。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **单机位**（机位克制：一步道/花坛角枪能看清角落坑与驱离路径即可） |
| **角度** | 步道—花坛角俯视约 45° |
| **覆盖** | 步道中段、花坛缺口、**古树根周**、**角落交接坑**、路灯死角边缘；禁止写镜头外绿化带深处塔位 |
| **不稳手机** | 本关**不开**老韩手机（前期少机制） |

### 地图与路线

三号花坛（聚阴古树）↔ 健身步道主段 ↔ **角落坑（交接角）**。傍晚回放干净；入夜碎光浮起，树根侧先脏；驱离路线须在单画面内可读。

### 可贴符位点

| 位点 | 说明 | 机位内 |
|---|---|---|
| 步道两侧 | 镇守削啃食队列；可**撕掉**让路 | ✓ |
| 花坛缺口 / 树根周 | 驱离锚点；把布丁往角引 | ✓ |
| **角落交接坑** | **定神**顶住布丁；召唤阴差落点 | ✓ |
| 路灯死角边缘 | 一大波前塔；可选驱离分流祟团 | ✓ |

### 波次

| 波 | 内容 |
|---|---|
| 傍晚回放 | 教学看「阳气完整＝干净」；认狗形布丁 |
| 入夜 1 | 碎光浮起，细祟趴地啃；教**撕符**拆开「布丁+祟团」混叠 |
| 入夜 2 | **驱离符**引布丁入角；攻击符误砸提示「会伤到它」 |
| **一大波** | 路灯一片灭：啃食高峰；须维持驱离链 + 角落定神不断 |
| 处理 | 定神满窗 → **召唤阴差**按钮亮；分支见下 |

### Boss

无；布丁为有名狗鬼（处理分支，非血条斩杀关）。

### 失败条件

步道**阳气被啃光**；或布丁被攻击符/失控潮**打碎**成祟；或定神断链逃出角落超时。

### 新机制（本关主课）

**驱离引角** + **撕符分离** + **定神顶住** + **召唤阴差带走**（阴差拒收普通祟团）。  
攻击符伤有名魂的警示。

### 处理分支（UI）

| 选项 | 说明 | 奖励 / 旗标 |
|---|---|---|
| **唤阴差带走（正道·主课）** | 定神后点召唤阴差；阴差收有名完整魂 | **写着「布丁」名字的项圈**；`布丁=阴差带走` |
| **驱散** | 攻击打散；无正道交接 | **无项圈或项圈残**；`布丁=驱散`；杀孽+ |
| **收服（次要）** | 定神后**不**唤阴差、收为伙伴；可灰显「后期」或并入「定神后选择留下」一句 | 无项圈（或另记伙伴旗）；`布丁=收服`；**仅此支**第10可助战 |

> 主 UI 优先两键：**唤阴差带走** / **驱散**。收服不抢主课文案。

### 关键对话 / 劝诫钩

> 老周：晚上不要在小区瞎转哦～人一走，剩的那点阳气，就归它们啃了。  
> 老周：那只黄的——**是狗**。不啃阳气。它在找放学的味道。驱离符把它**赶到那个角**，定神顶住，再叫阴差。五雷别砸它。  
> 老周：贴错了就**撕掉**。把狗跟旁边那团黑的分开，阴差才收得走。  
> 马科长：（若点祟团唤阴差）普通祟团不接收。有名的、完整的，再叫我。  
> 老韩：拉布拉多，可肥了。……东门外让车撞了。我埋花坛了。  
> *（若阴差带走）* 阴差：狗魂，有名。——项圈给你留个念想。  
> *（若驱散）* 小路：驱散单完成～额外奖励已到账哦～  
> 老周：（驱散后哼一声）碎了就碎了。后面找人，就靠监控和老韩的嘴了。

### 掉落 / 桌面

**阴差带走**：项圈特写进书桌（刻「布丁」）。

> 机位：**单路优先**（学府路人行段或护林小路一枪看清护送走廊）

- **路径**：学府路 / 护林小路旁 → 巷口边缘；祟团从监控死角、绿化带缝**堵路**。轻塔防找人 / 护「放学路」即可。

## 第 9 关｜空车棚·试探的影子 （温情线一·铺｜穿插｜非Boss）

> **整关换掉**原「浅梦出租屋 / 安神符」。无安神、不给人贴符、少人、单机位。为第10卧室 Boss 铺垫。

### 标题 / 订单与单主口述

**订单**
> 【驱祟单】学府路小区｜地下/架空**空车棚**固定枪  
> 症状：夜班保安回放里总有一团「人高的黑影」在车棚柱间试探，不伤车、专往有潮气的角落钻；业主说像有人在练走路  
> 报酬：180 元

**单主备注（物业夜班）**
> 人都不在画面里。就那道影子——像在找哪扇门更暖。别吓到住户就行。

### 塔防设定（定稿）

- **场景**：空车棚 / 空楼道口——**只见鬼影与环境**（柱、地锁、积水、监控噪点），**不见小禾本人**、少画全身人。  
- **路径**：盘踞细祟沿地锁缝、柱根、排水沟汇向**阴角**；一道**梦魇影子**（轮廓级）沿柱间试探，偶发「压低浓度」的雾带——像在物色下一处盘踞窝（铺垫第10卧室）。  
- **敌人目标**：灌满车棚浓度；影子试探「成功」叠层过高（视为找到更暖的门）。  
- **玩家目标**：单机位镇守清潮；可用**驱离**把细祟赶进可清区；**撕符**拆开「细祟粘在影子裙边」的混叠；可选对影子碎片**定神**短顶，再**召唤阴差**——阴差**拒收**普通祟团（马科长一句），仅当玩家定住「有名轮廓残渣」时才收（教学巩固，非主胜负也可纯打散潮）。  
- **机制尽量少**：本关主课 = **纯镇守清潮 + 撕符分离**（巩固第7撕符）；驱离/定神/唤阴差作可选巩固，不新开「对人」符。  
- **铜铃 / 红皮鞋**：仅环境音或热点半句，**不作对人主动技**。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **单机位** |
| **角度** | 车棚顶角 / 楼道口枪俯视约 45° |
| **覆盖** | 柱间通道、地锁缝、阴角汇潮点、排水沟口；影子全程在画内游走 |
| **少人** | 禁止住人近景；若需「惧值」用空镜浓度破线代替路人倒地 |

### 地图与路线

车棚入口缝 → 柱间走廊 → 阴角盘踞点；影子沿柱「走」一圈再压雾。可读：黑雾裙边拖着细祟。

### 可贴符位点

| 位点 | 说明 | 机位内 |
|---|---|---|
| 柱间两侧 | 镇守削细祟 | ✓ |
| 地锁 / 沟口 | 驱离分流；可撕 | ✓ |
| 阴角圈 | 可选定神短顶影子残渣 | ✓ |
| 入口镇宅 | 防回灌 | ✓ |

### 波次 / 阶段

| 阶段 | 内容 |
|---|---|
| 一 清棚 | 细祟沿地锁涌；教认「空棚只有鬼影」 |
| 二 影子入画 | 梦魇轮廓试探；撕符拆开粘边细祟 |
| **一大波** | 影子压雾 + 阴角双缝涌潮（无 Boss 血条） |
| 收束 | 潮清；热点：红皮鞋尺码印一闪 / 铜铃远音；结算「它找到更暖的门了——楼上某间卧室」 |

### Boss

无（影子试探 = 第10盘踞厉鬼的预习轮廓，非血条战）。

### 失败条件

车棚**浓度破线**；或影子试探叠层满（「门已选定」演出）超时未压住。可用「小禾惧值远程跳一下」作叙事花絮，但**手段仍是打/控/驱鬼**，无安神条。

### 新机制

无安神。巩固：**撕符分离**、镇守清潮；可选驱离/定神/唤阴差规则再提醒（阴差拒收祟团）。

### 关键对话 / 劝诫钩

> 老周：空车棚里没人。你打的是影子和细祟——别想着给人「镇静」。符是打鬼的。  
> 老周：贴错了就撕。让细祟别糊在那道影子上。  
> 马科长：（误唤）普通祟团不接收。  
> *（热点）* 红皮鞋印 / 铜铃远音——记一下，先清棚。  
> 结算便利贴：「下一单：林小禾卧室·守夜（硬仗）」。

### 掉落 / 桌面

侦察笔记「影子试探·上楼」。无安神符纸样张。

## 第 10 关｜林小禾卧室·梦魇 【首次Boss】（温情线一·结）

### 标题 / 订单与单主口述

**订单**
> 【驱祟单·守夜】学府路某小区｜**林小禾**卧室｜房间固定摄像头（**单路优先**）  
> 症状：晚自习后总觉得有人跟着；回家连续做噩梦；最近在**自己的房间**里像有东西盘踞  
> 报酬：220 元

**单主备注（林小禾）**
> 不好跟我妈说，她上夜班。以前有只狗每天来校门口接我……最近天花板那边像接上了巷子。师傅……能不能盯着点我房间里的东西？

### 塔防设定

- **路径**：祟从门缝、空调外机、窗帘缝渗入；厉鬼**盘踞**床周阳气窝；梦魇阶段门后可接**巷影**（表现层），但玩法是对**梦魇厉鬼/盘踞鬼**的**控场+输出**——**定神 / 镇宅 / 五雷 / 显形**等已有工具。  
- **删除**：**安神入梦**、安神条、给人贴符镇静——一律不做。  
- **敌人目标**：缠上小禾（惧值 / 梦魇缠上状态）；盘踞条涨满拖人「醒不过来」。  
- **玩家目标**：打掉 / 控住盘踞梦魇；清渗入潮。失败可用「小禾惧值破线 / 被梦魇缠上」描述，**手段必须打鬼**。  
- **布丁助战对齐第7**：  
  - `布丁=阴差带走` → **不助战**；项圈可作被动弱提示（危险点微亮 / 半拍预警）。  
  - `布丁=收服` → 可冲入助战（末段减负）。  
  - `布丁=驱散` → 无助战、潮更密。  
- **少人**：小禾以被窝轮廓 / 呼吸灯表示；少正脸全身。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **单机位优先**（房间角枪俯视约 45° 覆盖门/窗/床）；梦境叠化为同枪滤镜，不另开多路巩固 |
