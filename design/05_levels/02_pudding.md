## 第 7 关｜步道上的黄影子 （温情线一·起）

### 标题 / 订单与单主口述

**订单**
> 【驱祟单】锦华苑小区｜夜间步道 + 巡逻路线  
> 症状：连续半个月夜巡看到「黄白色肥敦敦的东西」在步道与花坛之间转；晚归业主说「路边黑影一排一排的」  
> 报酬：150 元｜单主手机 + 小区监控 3 路

**单主备注（老韩）**
> 我五十八了。那玩意儿老在三号花坛到步道那一段转。别弄太大动静。另外——人一走，路边就像有东西在……舔地。

### 塔防设定

- **路径逻辑**：人散后，步道上浮着**阳气碎渣**（余温碎光）；祟团沿步道—花坛来**啃食**。布丁在路线上转，不啃阳气，嗅「放学的味道」，祟冲向人时它会扑挡。  
- **吸引点**：**聚阴古树**——三号花坛侧一棵老树根阴沉，细祟爱趴根吸；路径锚在树—花坛缺口一段。  
- **敌人目标**：啃光碎渣；顺手扑晚归路人。  
- **玩家目标**：清开吸食中的细祟；接触布丁并做处理分支。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **多机位（3 路固定 + 可选临时）**——小区步道枪 + 花坛枪 + 保安亭枪；可附**老韩手机**一路（**不稳**：接电话/熄屏掉线，轻预告；关键塔仍靠固定枪） |
| **覆盖** | 步道中段两侧、花坛缺口、**古树根周**（须入花坛枪或步道边缘）、路灯死角、保安亭外；切到对应路才能贴 |
| **注意** | 路灯死角须落在「死角枪」或步道枪边缘；禁止写镜头外绿化带深处塔位 |

### 地图与路线

三号花坛（**聚阴古树**）↔ 健身步道主段 ↔ 路灯死角 ↔ 垃圾分类亭。傍晚回放人多无碎渣；入夜实时碎光浮起，树根侧先脏。

### 可贴符位点

| 位点 | 说明 | 所属机位 |
|---|---|---|
| 步道中段两侧 | 镇守，削啃食队列 | 步道枪 |
| 花坛缺口 / 古树根周 | 护布丁常转区；削树根吸食堆 | 花坛枪 |
| 路灯死角 | 一大波爆发点前塔 | 死角/步道边缘 |
| 保安亭外 | 护老韩镜头 | 保安亭枪 |

### 波次

| 波 | 内容 |
|---|---|
| 傍晚回放 | 教学看「阳气完整＝干净」 |
| 入夜 1 | 碎光浮起，细祟趴地啃 |
| 入夜 2 | 布丁入画；祟若冲老韩则扑挡（越扑越虚） |
| **一大波** | 一片路灯灭：啃食高峰 + 布丁连续扑挡 |
| 处理 | 驱散 / 报阴 / 约定（画物小游戏） |

### Boss

无；布丁为有名鬼（处理分支，非血条斩杀关）。

### 失败条件

步道**阳气被啃光**，或路人**冷 / 惧超阈值**（投诉条满）。

### 新机制

阳气碎渣视觉；有名鬼四种处理实战；**画物小游戏**（画球/火腿肠）。

### 关键对话 / 劝诫钩

> 老周：晚上不要在小区瞎转哦～人一走，剩的那点阳气，就归它们啃了。你看监控里那团团黑影，不是在散步，是在吃饭。  
> 老周：那只黄的不一样。它不啃阳气。它在找放学的味道。  
> 老韩：拉布拉多，可肥了。……东门外让车撞了。我埋花坛了。  
> *（若约定）* 你：我帮你留意——书包上挂你牌子的小孩。行吗？  
> *（布丁唯一一声有声音的「汪」。）*

### 掉落 / 桌面

D01 半截冰棍棍。约定：便利贴「找主人：书包狗牌·布丁」。驱散：图鉴变灰。

## 第 8 关｜狗牌 （温情线一·承）

### 标题 / 订单与单主口述

**触发**：仅当【布丁=约定】。否则替换「步道/花坛清祟」，并跳过第 9 关布丁冲入。

**订单**
> 【续单 / 线索单】锦华苑 → 学府路｜多路监控  
> 备注：帮一条狗找主人｜老韩自费 80 元

### 塔防设定

- **路径**：护送布丁沿学府路人流边 → 巷口；祟团从监控死角、绿化带缝**堵路**，欲冲散布丁执念体。  
- **敌人目标**：碰散布丁；吓退林小禾。  
- **玩家目标**：循牌找到小禾；轻护送布丁到巷口相遇（小禾看不见，布丁猛嗅）。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **多机位**——校门枪 → 学府路枪 → 巷口双岔枪（护送推进切换） |
| **覆盖** | 人行道镇守、巷口左右死角；**云台盲区**若当前路照不到则糯米位改到巷口入画处，或标「切到巷口枪后可用」 |
| **删/改** | 原「纯云台盲区、任何一路都照不到」的位点——改为巷口枪内临时糯米，或删 |

### 地图与路线

校门口监控段 → 学府路人行道 → 巷口死角双岔。可含 30–60 秒极短巷中塔防，不进 Boss 血条。

### 可贴符位点

| 位点 | 说明 | 所属机位 |
|---|---|---|
| 人行道两处镇守 | 护护送走廊 | 学府路枪 |
| 巷口左/右死角 | 一大波夹击点 | 巷口枪 |
| 巷口入画糯米位（可选） | 临时挡路（原云台盲区改入画） | 巷口枪 |

### 波次

| 波 | 内容 |
|---|---|
| 线索 | 调取 404 存档狗牌；校徽扣 |
| 护送 1 | 人行道细祟，布丁贴边走 |
| **一大波** | 巷口死角双路夹击 |
| 相遇 | 小禾回头：「……布丁？」 |

### Boss

无。

### 失败条件

布丁被冲散，或小禾**惧值破线**逃回家（线索中断，本关失败可重开）。

### 新机制

线索追踪；**轻护送**（无强制新符）。对话可答应「今晚守夜」铺垫第 9 关。

### 关键对话 / 劝诫钩

> 老周：晚自习后别一个人钻黑巷。——你帮她清路，她少走夜路。  
> 老周：别让祟团挨着它。它现在全是执念，一碰就散。  
> 你：还不能走。巷子里有东西。……今晚我守着她。

### 掉落 / 桌面

D10 校服校徽扣；狗牌特写打印件。便利贴「今晚·她的房间会做噩梦」。

## 第 9 关｜女孩的卧室·梦魇 【Boss】（温情线一·结）

### 标题 / 订单与单主口述

**订单**
> 【驱祟单·守夜】学府路某小区｜林小禾卧室｜手机床头支架 + 房间摄像头  
> 症状：晚自习后总觉得有人跟着；回家连续做噩梦；最近在**自己的房间**里醒不过来  
> 报酬：220 元

**单主备注（林小禾）**
> 不好跟我妈说，她上夜班。以前有只狗每天来校门口接我……最近梦里巷子会接上我的天花板。师傅……能不能看着我睡过去？

### 塔防设定

- **路径**：现实——祟从门缝、空调外机、窗帘缝渗入（把步道「吃饭的东西」带进家）；梦中——卧室门后接上**无限长巷**，黑雾沿巷涌向床。  
- **敌人目标**：破安神，把小禾拖进巷子睡死。  
- **玩家目标**：守夜安神 → 入梦打梦魇 →（条件）布丁冲入助战。

### 机位

| 项 | 定稿 |
|---|---|
| **数量** | **多机位**——房间摄像头 + 床头手机支架；梦境阶段同布局叠化/切「梦层」 |
| **角度** | 房间角枪俯视约 45° 覆盖门/窗/床；空调外机缝须入画或改「窗侧渗入」表现 |
| **覆盖** | 床头安神、门镇宅、窗八卦、梦中巷口两侧（梦层画面内） |

### 地图与路线

阶段一卧室：门 / 窗 / 空调三路 → 床头。  
阶段二梦境卧室：同布局，墙呼吸，门=巷入口。  
阶段三：门—巷接缝为布丁冲入点。

### 可贴符位点

| 位点 | 说明 | 所属机位 |
|---|---|---|
| 床头安神 | 主守护 | 床头/房间枪 |
| 门镇宅、窗八卦 | 现实渗入 | 房间枪 |
| 梦中巷口两侧 | Boss 阶段塔位 | 梦层画面 |
| 铜铃 | 打断蓄力 | UI |

### 波次 / 阶段

| 阶段 | 内容 |
|---|---|
| 一 守夜 | 短塔防；安神教学回顾；小禾入睡 |
| 二 梦魇 | Boss 三段血；二段起禁点；点阵藏雾；模仿小禾声 |
| **一大波** | Boss 二段禁点潮 +（条件）布丁冲入时接缝潮涌 |
| 三 收束 | 有布丁：末段五雷 5 点送分；无布丁：狂暴 8–9 点硬打 |

### Boss

**梦魇**（多阶段）：吃「一个人睡」与「布丁回不来」的怕。禁点、铜铃打断蓄力。

### 失败条件

安神破被拖入狂暴梦且超时；或 Boss 战小禾「醒不过来」判定失败。

### 新机制

Boss 多阶段；点阵藏雾；红色禁点；铜铃打断蓄力。

### 关键对话 / 劝诫钩

> 林小禾：牌子是布丁。……我没来得及说谢谢。  
> 你：别怕，狗牌我看着。  
> 梦魇：（叠声）她怕黑。你怕什么？  
> 你：我怕交不起房租。你能吃吗？  
> *（往生｜约定）* 小禾：（梦中）……布丁？你怎么还是这么圆啊。  
> 你：「去一个闻得见味道的地方。」  
> 结算小禾：今晚房间里没有巷子了。——房间本该是安全屋；你在屏幕这边值班，就是秩序一侧。
