## 1.1 一句话（Logline）

失业、失眠、欠着房租的年轻人，半夜在出租屋里接了一份「远程驱鬼」的零工——隔着手机镜头和小区监控画符捉鬼。你一单一单跑下去，慢慢发现：这座城市里所有的鬼，都连在同一口井上；而那口井，也在透过屏幕看着你。

## 1.2 类型与体量

| 项 | 设定 |
|---|---|
| 类型 | 叙事驱动 + 塔防布阵 + 记忆连笔画符（单线剧情，线性推进） |
| 体量 | **序章 + 约 24 关**（可调区间 22–25）；每关 4–7 分钟，重点关 8–12 分钟；含剧情约 **3–3.5 小时** |
| 视角 | 第一人称书桌视角（主界面）→ 放大到显示器内「路路捉鬼·师傅端」桌面应用（关卡界面） |
| 教学节奏 | **对标植物大战僵尸**：一关教一点，前段准教学关更碎、更简单；剧情与机制同步推进（详见 `04_gameplay_economy.md`） |

> 不再锁死「严格 20 关」。终章拆为可玩的多关，不为了凑数把终章压成无法游玩的过场。

## 1.3 指导思想 / 价值立场（design-v3.2 定稿）

> 用户偏传统：鬼故事、相声评书讲究**造化教育、劝人向善**；对标林正英——有鬼，也有人捉鬼。本条写入概述，并作为全文语气与分支设计的标尺。

### 可执行原则（不要口号堆砌）

1. **劝善落在「别做傻事」上，不落在道德演讲上。**  
   编鬼故事把人往「不要游野泳、晚上早点回家、别在小区瞎转、别逞能下渠下井」上劝——是好的。落实方式：步道阳气、四种处理后果、教学旁白里的**一句生活劝诫**；不打断节奏，不单独开「教育关」。

2. **聊斋逻辑：坏蛋娶不到狐仙。**  
   驱散有名鬼、贪平台单价、帮囡囡撕符写契约——短期「爽」或「钱多」，长期在功德/杀孽、Boss 强度、结局上吃亏。向善选择（送行、约定、报阴、留灯、听完故事）才换温情回收与结局 A。

3. **林正英对照：有鬼也有警察。**  
   现实有坏人就有警察；鬼世界有鬼有煞有祟，也有「路路捉鬼」保一方平安。**驱鬼者 = 秩序一侧**（警察隐喻）：你不是猎奇主播，也不是平台 KPI 的零件，你是夜里还在岗的那一边。老周、马科长、苏芮同属这一侧；平台鼓励驱散的贪婪是**「反劝善」对照**——像只认罚单金额、不认「把人送回家」的坏制度。

4. **语气：诡而不恶，冷中有暖，劝而不说教。**  
   恐吓感来自「人散之后谁在吃饭」；温暖来自「有人愿意听完」。小路甜美推驱散 = 反面教材；老周一句「晚上别瞎转」= 正面劝诫。玩家听得进就进，听不进也通关——但结局和旗标会记账。

5. **区分「鲁莽」与「勇敢」——赞颂英雄，拒绝犬儒。（design-v3.2）**  
   - **不鼓励**无价值、无意义的逞能冒险：游野泳、探墓破坏祭品、飙车、半夜下渠「找刺激」、为猎奇去捅镇物。这类在故事里用横死、祟团、差评式惨剧示警。  
   - **尊重并支持**真正的勇敢：明知可能暴露自己、丢单、被平台记过、甚至把祟引到自家，仍选择**帮同事、救人、守约、保一方平安**（如 Meta 关救芮姐、书桌自保、守布丁约定）。这是英勇无畏、舍己救人——要写得值得，要给叙事与结局上的肯定，**不要写成「好人没好报」的犬儒笑话**。  
   - 一句话：**傻冒险劝停；真英雄歌颂。**

6. **少人原则（design-v3.8 · 短而硬）**  
   尽量少让画面里出现「人」。人关节多、装扮杂，拖制作、也拖风格统一（写实 / 像素 / 方块皆然）。**机位与关卡优先：鬼、道具、环境、监控。** 必要人影用剪影、局部、远端小人。写机位先问：这一镜能不能靠香炉、面包、鬼影、路口讲完？

### 贯穿检查清单（写关 / 改对白时过一遍）

- [ ] 本关是否有一处**自然的生活劝诫**（可一句旁白 / 热点 / 结算）？  
- [ ] 驱散高收益是否被**后果**咬住（祟团、杀孽、淤、千怨）？  
- [ ] 驱鬼者是否显得在「保平安」，而非单纯打怪赚钱？  
- [ ] 平台 / 小路的贪婪台词是否能当**反劝善对照**读？  
- [ ] 若本关有「冒险」：是**鲁莽示警**，还是**英雄抉择**？后者是否被赞颂而非嘲讽？
- [ ] 画面是否偏少人：能靠鬼/道具/环境讲完的，不堆全身路人？

## 1.4 基调与恐怖定位

- **自评：中下恐。** 比微恐吓人一些，**无跳吓**；气氛参考林正英《僵尸先生》——符箓、铜铃、糯米、口诀，带一点黑色幽默，而不是现代惊吓片。**有鬼有人捉**，妖气与正气同框。
- **含 Meta 恐惧**：屏幕倒影、系统时间、第四面墙，服务「玩家自选身份」——你坐在屏幕这边，它有时也看着你。
- **诡而不恶，冷中有暖。** 画面是凌晨三点的出租屋、监控噪点、便利店白光、**电梯轿厢、小区步道、楼道感应灯**；故事落点是一只接放学的狗、一个超时的外卖小哥、一碗老太太再也煮不了的面。
- **零工经济的黑色幽默。** 驱鬼也要抢单、看评分、怕差评、被算法催；地府也在搞数字化，阴差也有 KPI。笑点来自现实，不来自嘲弄受害者。**平台催驱散 = 反劝善对照。**
- **屏幕上的符箓美学。** 「急急如律令」——全部经由摄像头、鼠标/触控，和一块发光的屏幕完成。桌上是电脑、零食与泡面，窗外半盏路灯；符画在屏上，连点成阵。

## 1.5 主题

1. **执念与放下**：鬼是放不下的人（或狗）。驱鬼不只是打，而是帮对方把没说完的话说完。——**劝善：听完比打碎贵，也更对。**
2. **打碎不等于解决**：把完整的鬼打碎来钱最快，但执念不会消失，只会碎成**祟团**，被吸阴之物与地下怨脉吞没，越积越大（本作核心反转）。——**劝善：贪快贪钱，井里的东西高兴。**
3. **隔着屏幕的善意与恶意**：远程工作让人与人（与鬼）之间隔了一层玻璃。玻璃上的倒影，始终是你自己。
4. **秩序一侧（design-v3.2）**：路路捉鬼、阴差、老周——像夜里还在岗的警察。有祟必达，不是猎奇，是保一方平安；玩家成长弧从「为钱接单」到「为人接单」，正是从「零工零件」走到「秩序一侧」。
