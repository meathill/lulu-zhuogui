## 1.1 一句话（Logline）

失业、失眠、欠着房租的年轻人，半夜在出租屋里接了一份「远程驱鬼」的零工——隔着手机镜头和小区监控画符捉鬼。你一单一单跑下去，慢慢发现：这座城市里所有的鬼，都连在同一口井上；而那口井，也在透过屏幕看着你。

## 1.2 类型与体量

| 项 | 设定 |
|---|---|
| 类型 | 叙事驱动 + 塔防布阵 + 记忆连笔画符（单线剧情，线性推进） |
| 体量 | **序章 + 25 关**（可调区间 22–25）；每关 4–7 分钟，重点关 8–12 分钟；含剧情约 **3–3.5 小时** |
| 视角 | 第一人称书桌视角（主界面）→ 放大到显示器内「路路捉鬼·师傅端」桌面应用（关卡界面） |
| 教学节奏 | **对标植物大战僵尸**：一关教一点，前段准教学关更碎、更简单；剧情与机制同步推进（详见 `04_gameplay_economy.md`） |

> 不再锁死「严格 20 关」。终章拆为可玩的多关，不为了凑数把终章压成无法游玩的过场。

## 1.3 指导思想 / 价值立场（design-v4.1 定稿）

> 用户偏传统：鬼故事、相声评书讲究**造化教育、劝人向善**；对标林正英——有鬼，也有人捉鬼。本条写入概述，并作为全文语气与分支设计的标尺。

### 可执行原则（不要口号堆砌）

1. **劝善落在「别做傻事」上，不落在道德演讲上。**  
   编鬼故事把人往「不要游野泳、晚上早点回家、别在小区瞎转、别逞能下渠下井」上劝——是好的。落实方式：步道阳气、四种处理后果、教学旁白里的**一句生活劝诫**；不打断节奏，不单独开「教育关」。

2. **聊斋逻辑：坏蛋娶不到狐仙。**  
   驱散有名鬼、贪平台单价、帮囡囡撕符写契约——短期「爽」或「钱多」，长期在功德/杀孽、Boss 强度、结局上吃亏。向善选择（送行、收服、报阴、留灯、听完故事）才换温情回收与结局 A。

3. **林正英对照：公办秩序一侧（派出所管人间，我们管阴间杂事）。**  
   现实有坏人就有警察，超自然有煞有祟也有人值守。**「路路捉鬼」是半个事业单位，挂在市宗教局下面，业务归辖区派出所管，基本上还是公办单位做派**（老周名言：「派出所管人间，我们帮忙处理点阴间杂事」）。你不是冷血的外包散工，也不是猎奇主播，你是夜里还在岗的守夜秩序。马科长（地府夜巡科）属于阴司对口部门，两边是体制内跨部门协作；平台个别人贪驱散单价是由于考核结案率与图省事的官僚懒政，作为**反劝善对照**。

3b. **叙事质感：警察模式 vs 侦探模式（基层公办的沉闷枯燥 vs 浪漫悬疑的奇观）。**  
   - **侦探是浪漫的**：带着美女助手住进暴风雪山庄，面对身世复杂的怪人和不可思议的作案手法，在华丽的智斗中抓住破绽破案，让人着迷。  
   - **警察是沉闷的**：现实破案靠的是基层民警排查信息、核对成百上千个小时的监控、挨家挨户敲门走访问“昨晚听到什么没有”。罪犯多是灰头土脸的普通人，大多是一时兴起的激情犯事。看法制节目除了觉得民警辛苦，大部分流程其实枯燥乏味。  
   - **老周的日常与乏味感**：老周作为统管多名夜巡人员的老基层带班，对他而言，每天画符、清祟、管夜班是几十年的日常常态，乏味得像老警察天天走访核实。他的话里充满**沧桑、乏味、疲惫、务实与“差不多就行了”**的质感。情绪波动极小，见怪不怪，不搞大呼小叫的高人说教：“行了，把门缝堵严实点，别折腾大阵，结了单早点交班。”  
   - **动静对照与人情味**：玩家是新入职的普通人，会面对新奇危险的挑战与心理起伏；老周是不惊不乍的沉闷底色；而其他配角（苏芮的泼辣护短、老秦的交警旧事、老韩的家长里短、马科长对地府清淤指标的官僚吐槽）则会多跟玩家聊自身经历、世界设定或听来的坊间传闻，在沉闷枯燥的基层常态中展开丰富的人间温度。

3c. **叙事原型：小地方刑警遇到大案子（城镇化狂飙与民间信仰循环断裂）。**  
   - **类型映射**：典型中国当代现实主义涉案剧质感（如《漫长的季节》）。主角本来只是每天隔着监控查查水电气、清理点零碎生活阴祟的小县城夜班守夜人，却在不知不觉中撞上了下水道深处汇聚爆发的三十年诅咒与怨念聚合体。  
   - **核心病灶（彻底摒弃“邪恶公司把鬼打碎”的西式阴谋论套路）**：  
     恶煞的集中爆发，**绝不是哪家资本公司为了搞钱指使员工打碎鬼魂导致的**。深层病因是过去三十年**城镇化狂飙突进与急剧经济发展**，把原本千百年来运转平衡的**民间信仰循环彻底打破了**——大拆大建推平了老街与古槐神龛，乡村宗祠与土地庙被毁，生者被生活追赶得顾不上哀悼，逝者来不及告别与安放。无处安放的三十年民间苦难与执念，顺着城市暗渠沉淀沉沦，在临江市一次性总爆发。  
   - **水下冰山设定（全国大势与芮姐未婚夫案，剧本保持克制）**：  
     类似的地脉失衡在全国都在同步发生，甚至有比我们更懂鬼神的圈内势力想趁乱作祟搞事情——这正是苏芮未婚夫林峰（工号 0412）当年暗中追查并遭遇的真正凶险。**本剧本对此极其克制，仅作冰山水下留白，绝不喧宾夺主展开庞大阴谋**，镜头始终聚焦在临江市这间破旧值班室与基层老百姓的人情冷暖上。

4. **语气：诡而不恶，冷中有暖，劝而不说教。**  
   恐吓感来自「人散之后谁在吃饭」；温暖来自「有人愿意听完」。小路标准政务女声催达标 = 反面教材；老周一句「晚上别瞎转」= 正面劝诫。玩家听得进就进，听不进也通关——但结局和旗标会记账。

5. **故事创作铁律：先写背景设定，再写台词与任务描述。**  
   拒绝空中楼阁式的脸谱化对白。每个鬼生前都是具体生活着的人（或狗），有完整的生活轨迹与前因后果。写每一关前，**必须先交代清晰的背景设定**，再落笔写台词、口述与任务备注，才能自然饱满，杜绝莫名其妙。

6. **区分「鲁莽」与「勇敢」——赞颂英雄，拒绝犬儒。（design-v4.1）**  
   - **不鼓励**无价值、无意义的逞能冒险：游野泳、探墓破坏祭品、飙车、半夜下渠「找刺激」、为猎奇去捅镇物。这类在故事里用横死、祟团、差评式惨剧示警。  
   - **尊重并支持**真正的勇敢：明知可能暴露自己、丢单、被记过、甚至把祟引到自家，仍选择**帮同事、救人、守约、保一方平安**（如 Meta 关救芮姐、书桌自保）。布丁即便被阴差带走，**不肯踏上奈何桥，冒着魂飞魄散逆冲黄泉回阳间救小主人**——这是真正的舍身之勇，要写得震人心魄。  
   - 一句话：**傻冒险劝停；真英雄歌颂。**

7. **少人原则（短而硬）**  
   尽量少让画面里出现「人」。人关节多、装扮杂，拖制作、也拖风格统一（写实 / 像素 / 方块皆然）。**机位与关卡优先：鬼、道具、环境、监控。** 必要人影用剪影、局部、远端小人。写机位先问：这一镜能不能靠香炉、面包、鬼影、路口讲完？

8. **机位克制（v4.1）**  
   默认**单机位**。多机位仅当明显增加难度或服务剧情；前期/策划阶段能少机制就少。教学弧与布丁弧凡可单路改回单路。第5「多机位首教」若保留，注明是**少数例外**并说明为何需要；第6及以后不要为巩固而强开多机位。

9. **符箓实战与位置规则（v4.2 定稿）**  
   - **符只能贴在屋内/环境位置上**（门框、门下缝、窗台、走廊地面、灶台旁等），在空间中形成镇守结界，对经过的鬼祟起效；  
   - **唯独活人被「附身」时**（如第3关醉汉），显形/净眼类符才可以直接贴在活人身上（后颈、额头），逼出阴煞；  
   - **五雷符等攻击符**：不需要往鬼身上硬贴，**扔在选定地面上引天雷**，炸碎阴气即可。

10. **撕符（v4.1）**  
    所有已贴符可**手动撕掉**（回收位点/打断效果），用来把不同魂分开。

11. **定神→召唤阴差（v4.1）**  
    定神后 UI **召唤阴差按钮**；阴差只收完整/有名魂，**普通祟团不接收**。布丁被阴差带走后，在第10关不肯上奈何桥、逆冲黄泉返阳救小禾，实现情感大高潮。

### 贯穿检查清单（写关 / 改对白时过一遍）

- [ ] 本关是否有一处**自然的生活劝诫**（可一句旁白 / 热点 / 结算）？  
- [ ] 驱散高收益是否被**后果**咬住（祟团、杀孽、淤、千怨）？  
- [ ] 驱鬼者是否显得在「保平安」，而非单纯打怪赚钱？  
- [ ] 平台 / 小路的贪婪台词是否能当**反劝善对照**读？  
- [ ] 若本关有「冒险」：是**鲁莽示警**，还是**英雄抉择**？后者是否被赞颂而非嘲讽？
- [ ] 画面是否偏少人：能靠鬼/道具/环境讲完的，不堆全身路人？
- [ ] 机位是否默认单路？多机位是否写清例外理由？
- [ ] 符是否只打鬼祟？符位是否落在鬼的路径与位点？
- [ ] 已贴符能否撕？定神后是否接召唤阴差（且拒收祟团）？

## 1.4 基调与恐怖定位

- **自评：中下恐。** 比微恐吓人一些，**无跳吓**；气氛参考林正英《僵尸先生》——符箓、铜铃、糯米、口诀，带一点黑色幽默，而不是现代惊吓片。**有鬼有人捉**，妖气与正气同框。
- **含 Meta 恐惧**：屏幕倒影、系统时间、第四面墙，服务「玩家自选身份」——你坐在屏幕这边，它有时也看着你。
- **诡而不恶，冷中有暖。** 画面是凌晨三点的出租屋、监控噪点、便利店白光、**电梯轿厢、小区步道、楼道感应灯**；故事落点是一只接放学的狗、一个超时的外卖小哥、一碗老太太再也煮不了的面。
- **零工经济的黑色幽默。** 驱鬼也要抢单、看评分、怕差评、被算法催；地府也在搞数字化，阴差也有 KPI。笑点来自现实，不来自嘲弄受害者。**平台催驱散 = 反劝善对照。**
- **屏幕上的符箓美学。** 「急急如律令」——全部经由摄像头、鼠标/触控，和一块发光的屏幕完成。桌上是电脑、零食与泡面，窗外半盏路灯；符画在屏上，连点成阵。

## 1.5 主题

1. **执念与放下**：鬼是放不下的人（或狗）。驱鬼不只是打，而是帮对方把没说完的话说完。——**劝善：听完比打碎贵，也更对。**
2. **打碎不等于解决**：把完整的鬼打碎来钱最快，但执念不会消失，只会碎成**祟团**，被吸阴之物与地下怨脉吞没，越积越大（本作核心反转）。——**劝善：贪快贪钱，井里的东西高兴。**
3. **隔着屏幕的善意与恶意**：远程工作让人与人（与鬼）之间隔了一层玻璃。玻璃上的倒影，始终是你自己。
4. **秩序一侧（design-v4.1）**：路路捉鬼、阴差、老周——像夜里还在岗的警察。有祟必达，不是猎奇，是保一方平安；玩家成长弧从「为钱接单」到「为人接单」，正是从「零工零件」走到「秩序一侧」。
